## 위험 표

| 아이디어 (칸 위치와 글 그대로) | 개인정보 | 저작권 · 초상권 | 편향 | 책임 소재 | 먼저 확인할 것 ★ |
|---|---|---|---|---|---|
| ① 3단계 × 생성 — "J1: 두 매물 글에서 값에 든 것·빠진 것을 나란히 정리한 매물 정리 카드 초안" | 판매자 닉네임 · 연락처, 사진 속 배 이름이 카드에 따라 옮겨질 수 있음 → 판매 선주, 팀 담당자 | 판매자가 쓴 글과 올린 사진을 카드로 옮겨 씀 → 판매 선주(권리자), 당근마켓 이용약관 | 글을 길게 쓴 매물은 믿음직해 보이고 짧게 쓴 매물은 불리해 보일 수 있음 → 팀 검수자 | 카드에 옮긴 값이 틀리면 윤 씨가 그것을 보고 고름 → 카드 게시 승인자 (팀이 정함) | ★ 저작권 · 초상권 |
| ② 3단계 × 자동화 — "J3: 옮긴 매물 글에 사용시간·정비 이력·연식이 적혔는지 칸마다 세기" | 옮겨 둔 매물 원본에 닉네임이 남을 수 있음 → 팀 담당자 (`data/`와 `inputs/` 가운데 어디 둘지) | 매물 원문을 모으는 범위 → 당근마켓 이용약관 | 다른 말("운항 시간" 등)로 쓴 글을 놓쳐 "안 적음"으로 셀 수 있음 → 원문을 대조할 팀 검수자 | "0건" 같은 숫자가 틀린 채 화면에 나감 → 숫자 확인자 (팀이 정함) | ★ 편향 |
| ③ 4단계 × 생성 — "J1: 법령 사본·KNN 보도에서 산 뒤 생길 기한과 돈을 원문 링크와 함께 쉬운 말로 풀어 쓴 안내 초안" | 손님이 자기 배 이름 · 등록번호를 넣어 물으면 함께 처리될 수 있음 → 손님 동의 | KNN 보도 문장, 법령 본문을 옮기는 범위 → KNN(권리자), 국가법령정보센터 이용 안내 | 쉬운 말로 줄이다가 예외 조항이 빠져 특정 배 주인에게 틀린 안내가 갈 수 있음 → 법령 본문 대조자 | 기한이 틀리게 안내되면 손님이 기한을 넘김 → 안내 게시 승인자, 등록 관청 [확인 필요] | ★ 책임 소재 |
| ④ 5단계 × 생성 — "J2: 매물 글에서 빠진 항목으로 판매자에게 물어볼 질문 넷 초안" | 매물 글을 넣을 때 판매자 연락처가 섞일 수 있음 → 판매 선주, 팀 담당자 | 매물 글 일부를 질문에 인용함 → 판매 선주 | 판매자를 처음부터 의심하는 말투로 쓰일 수 있음 → 판매 선주에게 질문을 시험해 보기 | 중요한 질문이 빠졌는데 윤 씨는 넷만 물음 → 질문 목록 승인자 (팀이 정함) | ★ 책임 소재 |
| ⑤ 7단계 × 생성 — "J1: 변경등록 서류·기한 체크리스트 초안 (공식 본문 대조 전 표시)" | 채우는 칸을 만들면 신분증 · 등록증 번호가 들어올 수 있음 → 손님 동의, 개인정보 담당자 (팀이 정함) | 법령 본문을 옮기는 범위 → 국가법령정보센터 이용 안내 | 부산 기준만 적으면 다른 지역 손님에게 다른 절차가 안내될 수 있음 → 등록 관청 [확인 필요] | 서류가 빠지거나 기한이 틀림 → 체크리스트 승인자, 등록 관청 [확인 필요] | ★ 책임 소재 |
