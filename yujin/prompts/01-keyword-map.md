# 조립형 프롬프트 ① 부산 중고 요트 키워드 맵 (마린딜러)

> 세 칸을 내 말로 채워 저장한 뒤, Claude Code에 '이 파일을 열어 할 일을 실행해 줘' 한 줄을 보냅니다.
> 출발점은 `busan_used_yacht_platform_plan.md` 하나입니다.

## 완성 프롬프트

```text
[1. 나의 기획 목적]
마린딜러 프로토타입 기능(시세 추정, 계류지 지도, 사고 위험도, 거래 절차 안내) 중 공공데이터로 바로 만들 수 있는 것을 고르기 위해, 부산 중고 요트 거래의 문제와 데이터를 한 장에 모은다

[2. 최우선 판단 기준(우선순위)]
① data 파일 행 번호나 직접 연 URL로 근거를 댈 수 있다 ② 2025~2026년 자료다 ③ 마린딜러 기능 하나로 바로 이어진다

[3. 타깃 대상 및 제외할 노이즈]
타깃: 수영만 재개발로 계류지를 잃고 요트를 팔려는 부산 선주. 뺄 것: 사고위치가 빈 행, 발생일자가 망가진 칸, 일본 자료(보조라서 이번 맵에서는 뺌)

할 일:
1. data/ 폴더의 파일을 먼저 읽어. 파일마다 행 수와 컬럼 이름을 표로 보여 줘. SOURCE.md의 '함께 읽을 점'과 다르면 알려 줘.
2. 위 [2]의 순서대로 키워드 12개 이상을 골라 keyword-map.md의 키워드 표를 채워. 묶음은 3개 이상.
3. 키워드마다 근거를 'data 파일의 몇 번째 행(머리줄 = 1행)' 또는 '직접 연 웹 페이지 URL'로 적어. 근거가 없으면 상태 칸에 '확인 필요'라고 써.
4. [3]의 제외 조건에 걸린 것은 넣지 말고, keyword-map.md의 '뺀 것' 표에 이유와 함께 따로 적어.
5. 기관이 밝히지 않은 이유는 '가설:'로 시작해.
```

## 붙여 넣은 뒤 확인

- [ ] 키워드마다 근거(파일 행 또는 URL)가 있다
- [ ] '뺀 것' 목록이 있고, 내가 [3]에 쓴 조건과 맞다
- [ ] 숫자는 data 파일의 숫자와 똑같다(반올림하거나 바꾸지 않았다)
