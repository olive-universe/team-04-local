# 조립형 프롬프트 ③ 데이터·서비스 트랙 · 분모가 붙은 숫자로 지역 비교 (마린딜러)

> 세 칸을 내 말로 채워 저장한 뒤, Claude Code에 '이 파일을 열어 할 일을 실행해 줘' 한 줄을 보냅니다.
> 출발점은 `busan_used_yacht_platform_plan.md` 하나입니다.

## 완성 프롬프트

```text
[1. 나의 기획 목적]
부산 앞바다 어느 구·군에서 선박 사고가 많은지 같은 분모로 비교해, 마린딜러 사고 위험도 화면과 계류지 지도에서 먼저 보여 줄 지역 순서를 정한다

[2. 최우선 판단 기준(우선순위)]
① 분모가 붙은 비중 (부산 사고 레코드 중 몇 %) ② 사고위치 글에 구·군 이름이 적혀 있음 ③ 요트 계류지(수영만·남천·운촌항)가 있는 구와 겹치는지

[3. 타깃 대상 및 제외할 노이즈]
타깃: 해운대·수영 일대에 요트를 둔 선주. 뺄 것: 사고위치가 빈 행, 구·군 이름이 없거나 둘 이상인 행 (빼되 몇 개인지는 적음)

할 일:
1. 기준에 필요한 칸이 data/ 파일 어디에 있는지 표로 보여 줘. 없는 것은 '이 데이터에는 없음'이라고 써.
2. '뺀 행' 표를 먼저 만들어. 무엇을, 몇 개, 왜 뺐는지.
3. 구·군별 사고 레코드 수와 비중을 표로 만들어. 비중마다 분모를 함께 적고, 레코드 번호 예시를 붙여.
4. 계류지가 있는 구(해운대구·수영구)는 표에서 따로 표시하고, 지명(수영만·동백섬·광안 등)으로도 세어 봐.
5. 표로 말할 수 없는 해석은 '가설:'로 시작해. 매출·선박 종류처럼 표에 없는 것은 지어내지 마.
7. 결과를 research/에 트랙 노트 한 장으로 저장하고, keyword-map.md에 키워드 한 줄을 더해.
```

## 붙여 넣은 뒤 확인

- [ ] 비중마다 분모가 적혀 있다
- [ ] 레코드 번호로 다시 찾아볼 수 있다
- [ ] '뺀 행' 표가 추천보다 먼저 나온다
