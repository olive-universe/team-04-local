## 2026-11-24 융합 결정 · 가게 메뉴판 → 자갈치시장 먹거리 안내

- 위 주제를 그대로 두고, 부산올랭이 이미 AI 번역(여섯 언어)을 한다는 것을 확인한 뒤(`research/2026-11-24-손님불편-돈낼사람-부산올랭기능.md`) 이렇게 넓혔다.
- 한 줄 [제안, 팀 확인 전]: "가게 메뉴판이 모여, 시장 먹거리 안내가 된다."
- 단계: 1단계 가게 (사장님 한 분의 메뉴판 사진 → 바로 붙이는 외국어 카드) → 2단계 시장 (카드가 모여 **자갈치시장** 외국어 먹거리 안내) → 3단계 크루즈 (배 떠나기 전 코스, 나중)
- 시장: **자갈치시장** 하나 (`inputs/busan_markets.csv:157` "자갈치시장,상설장,부산광역시 중구 자갈치해안로 52" … "223,수산물+음식점업")
- 첫 고객 [검증 전 가설]: 자갈치시장 안이나 바로 옆에서 혼자 식당을 하는 사장님 한 사람
- 부산올랭과의 관계: 번역은 부산올랭이 하고, 우리는 "사장님이 쓰기까지의 마지막 한 걸음"과 "시장 단위로 모아 보여 주기"를 한다 [가설]
- 데모데이(12월 22일)에 보여 줄 것 [제안]: 가게 3~5곳의 카드 + 자갈치시장 안내 페이지 1장. 크루즈는 '다음 단계' 한 장
- 보류: 부산올랭 사이트(menu.busan.go.kr) 직접 확인 — [확인 필요: 음식 설명 칸, 시장별 모아 보기 기능 유무]. 사용자 결정으로 일단 비워 둠
- 주의 [내 판단]: 자갈치시장 가게는 회·활어처럼 시세로 값이 바뀌는 메뉴가 많을 수 있다. 고정 메뉴판이 맞는지 현장에서 본다
- 카드에 담는 것 [제안, 2026-11-24 사용자 결정]: 음식 이름(4개 국어) · **재료 설명** · 맵기 · 피할 재료 표시(돼지고기·갑각류 등). **값은 넣지 않는다** — 카드는 "값은 사장님께 물어보세요"로 적어 한 번 만들면 오래 쓴다 (시세 메뉴와 고령 점주의 고치는 부담 때문, 가설)
- 재료 규칙: AI는 재료 **후보**만 쓴다. 사장님이 하나씩 확인한 것만 카드에 "사장님 확인함(날짜)"으로 올린다. 확인 안 된 재료는 "사장님께 물어보세요"로 남긴다. "알레르기 걱정 없음" 같은 보장은 쓰지 않는다
- 가설: 번역은 부산올랭이 하지만, 자갈치시장 생선·해산물이 **무엇으로 만든 음식인지** 알려 주는 것은 단순 번역과 다른 일이다. [확인 필요: 부산올랭에 재료 칸이 있는지 · 손님이 실제로 재료를 묻는지]
- 이미 하는 곳 (2026-11-24 확인, `research/2026-11-24-재료설명-근거-경쟁.md`): 부산올랭(번역·QR) · 파파고(손님이 메뉴판을 찍어 음식 이름 번역, 한국관광공사 메뉴명 DB 약 2만5000개) · 음식 관광 누리집 Foodtrip.or.kr(약 400개 음식의 일반 재료·조리법). 그래서 우리 차별점은 번역이 아니라 **"그 가게 음식의 실제 재료를 사장님이 확인한 카드" + "자갈치시장 단위 모아 보기"**다 [가설]

## 서비스 정의 (2026-11-24 · 팀 확인 전 [제안])

- 한 줄: "번역은 앱이 하고, 재료는 사장님이 확인해요. 그 카드가 모여 자갈치시장 먹거리 안내가 돼요."
- 분야: **푸드**가 주 분야 (식당·음식·주문 단계) · 리테일은 2단계 연결 (자갈치시장 = 전통시장) · 콘텐츠는 만드는 방법 (재료 설명·4개 언어 소개) · 뷰티는 해당 없음
- 쓰는 사람: 자갈치시장 안이나 옆에서 혼자 식당을 하는 사장님 (가설) · 보는 사람: 자갈치시장에 온 외국인 손님
- 주는 것 ① 가게 카드: 음식 이름 4개 언어 · 재료(AI 후보 → 사장님이 체크한 것만 '확인함') · 맵기 · 피할 재료(식약처 알레르기 목록) · 값 없음
- 주는 것 ② 자갈치시장 안내: 카드가 모인 한 페이지
- 안 하는 것: 새 번역 앱, 값·주문·결제, 재료·알레르기 보장, 시장 여러 곳
- 핵심 가설: 기존 도구(부산올랭·파파고·Foodtrip)는 일반 정보만 준다. "그 가게 음식의 실제 재료를 사장님이 확인한 정보"는 아무도 안 준다
- 데모데이: 자갈치시장 가게 3~5곳의 실제 카드 + 시장 안내 1페이지 + 크루즈 '다음 단계' 한 장
- 셀 숫자: 카드를 만든 가게 수 · 사장님이 고친 재료 줄 수 · 실제로 붙인 카드 수
- 현장에서 풀 것: 손님이 재료를 묻나 · 사장님이 체크해 줄까 · 누가 돈을 내나
