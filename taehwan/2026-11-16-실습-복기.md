### 인사이트 3가지 (분모 78건)

1. **78건 중 27건이 광안대교 뷰·야경 이야기.** → "광안대교 너무 예쁨. 야경은 덤" (45)
2. **불꽃 이야기는 5건, 드론쇼는 7건.** 불꽃 5건 중 4건이 축제 직후(11/7~11/15)에 쓰였다. → 축제 당일 경험은 카카오맵만으로 부족
3. **불편은 주차·사람 많음에 모임 (9건).** → "주차하기가 힘들고" · "주차비가 비쌉니다." (23)

### 필드워크로 알게 된 것

- 구글맵 외국어 리뷰 26건 중 청결 이야기 4건, **모두 "깨끗하다"**, 더럽다는 0건
- 2026년 부산시 교통 통제 공지(2026-10-30)에는 **주차 안내·대중교통 이용 권장 문장이 없었다** — https://www.busan.go.kr/nbnews/1761578
- 2025년 제20회 축제는 **2025-11-15** — https://www.busan.go.kr/nbnews/1705229

## 2. 중요하다고 생각한 것

- **원본은 고치지 않고 따로 둔다.** 통째로 복사한 글은 내 PC(`raw/`)에만 두고, 정리본만 팀 저장소에 올렸다.
- **모르는 값은 지어내지 않는다.** 별점이 안 복사돼서 빈칸으로 뒀다. 글에 축제라는 말이 없는 후기("2026.11.07 빛나던 그날")는 "가설"로만 적었다.
- **번역본은 원문이 아니다.** 구글맵은 외국어 리뷰를 자동 번역해서 보여 준다. "원본 보기"를 눌러 원문만 썼다.
- **장소가 바뀌면 기준표도 바꿔야 한다.** 허심청(온천)용 태그는 광안리 후기 78건 중 11건에만 맞았다.

## 3. 막혔던 것과 푼 방법

| 막힌 것 | 푼 방법 |
|---|---|
| 프롬프트의 `○○○` 칸을 안 채우고 보냄 | 장소·목적을 광안리로 채워서 다시 진행 |
| 카카오맵 첫 복사본이 '유용한 순'과 '최신순'이 섞임 | 정렬을 최신 순으로 바꿔 다시 복사 |
| 복사한 글에 후기별 **별점이 없음** ("별점평균"은 글쓴이 평균) | 별점 칸을 빈칸으로 두고, 리포트에 '말할 수 없는 것'으로 적음 |
| 구글맵 외국어 리뷰가 **번역본으로 복사**됨 | 리뷰마다 "원본 보기"를 눌러 다시 복사 |
| 낱말 세기가 틀림 ("부산아이가!"가 '아이 손님'에 걸림, "비쌉니다"는 '비싸'에 안 걸림) | 낱말 규칙 값과 사람이 읽은 값을 둘 다 적음 |
| git 저장소가 OneDrive 폴더 전체를 잡고 있었음 | `llm-academy`만 따로 저장소로 만들고, 팀 저장소에는 `taehwan/` 폴더로 올림 |
| 계획서가 수업 기준("한 줄 = 소스 하나 · 담당 한 사람")과 달랐음 | 카카오맵 줄을 빼고, '확인할 것'을 질문 한 줄로 줄임 |

## 4. 질문 (#학습질문)

1. 카카오맵을 통째로 복사하면 **후기별 별점이 남지 않습니다.** 별점까지 보려면 손으로 옮겨 적는 것 말고 다른 방법이 있을까요?
2. 구글맵은 작성일이 "5일 전", "1개월 전"처럼만 나옵니다. 모은 날을 기준으로 **날짜로 바꿔 적어도 되나요**, 아니면 표기 그대로 두는 게 맞나요?
3. 수업 기준은 후기 30~50건인데, 저희는 글이 있는 후기를 전부 써서 **78건**으로 분석했습니다. 건수를 기준에 맞춰 줄여야 할까요?
4. 오전에 만든 리뷰 태그 기준표(온천용)가 해변에는 거의 안 맞았습니다. **장소마다 기준표를 새로 만드는 게** 맞는 방법인가요?
5. 공식 자료에서 "주차 안내가 **없었다**"는 것은 열어 본 페이지에 없었다는 것뿐인데, 노트에는 어떻게 쓰는 게 좋을까요? (지금은 "열어 본 페이지에서는 찾지 못했다 + 가설"로 썼습니다)
