# 부산 웰니스 기획 전환 계획

**목표:** 광안리 축제 중심 기획을 부산의 휴식·식사·뷰티·쇼핑 경험을 연결하는 웰니스 서비스 기획으로 전환한다.

**사용자 결정:** 주제를 웰니스로 바꾸고 재사용할 광안리 요소는 살린다. 세부 선택은 최선의 판단에 맡긴다. 원본은 보존하고 팀 공유는 복사본으로 한다.

**진행 방식:** 문서 작업을 현재 작업 폴더에서 직접 진행한다. 앱 개발, 시설 투자, 업체 계약, 외부 업로드는 이번 범위에 없다.

**선택한 방향:** 외국인 개별 여행객을 위한 광안리 반나절 웰니스 코스 안내와 기존 업체 예약 연결. 기존 자료 재사용이 가능하고 시설을 직접 만들기 전에 수요를 확인할 수 있다. 고객·수익·서비스 필요성은 검증 전 가설이다.

**비교한 대안:** 부산 거주자 대상 반복 이용 멤버십은 재방문 검증이 필요하다. 기장 공간 직접 조성은 입지·자금·운영 검토가 선행돼야 하므로 확장 후보로 둔다.

## 작업과 확인

- [x] 공식 출처를 research/에 기록한다. 부산의 지정 관광지 수와 전체 사업체 수를 구분하고 수도권 대비 부족 주장을 사실로 쓰지 않는다.
- [x] wellness/에 한 장 기획서, 고객·브랜드, 산업 후보, 지역 자산, 현장조사, 데이터 명세, 발표안과 세계관을 작성한다. 수익·가격·제휴·의학적 효과를 확인된 사실처럼 쓰지 않는다.
- [x] 기존 활성 진입 문서에 새 기획 경로를 안내한다. 이전 기획은 그대로 남기고 활성 문서 상단에 이전 기획임을 명시한다. 예전 리뷰·세그먼트를 새 수요의 근거로 옮기지 않는다.
- [x] team-share/busan_02/wellness/에 새 문서의 공유용 복사본만 준비한다. 외부 전송은 하지 않는다.
- [x] 링크·출처·가설 표시·원본 보존·복사본 일치 여부를 확인하고 변경 내역을 알린다.

## 공통 기준

- 푸드·리테일·콘텐츠·뷰티는 이번 과제의 네 가지 연결 분야이며 CJ의 공식 산업 분류라고 단정하지 않는다.
- 광안리는 초기 검증 지역이다. 동래·해운대·기장은 별도 코스 후보이며 이동시간을 확인하기 전 하나의 일정으로 묶지 않는다.
- 알려진 관광자원 존재, 실제 이용 가능, 제휴 체결, 고객 지불 의사를 각각 구분한다.
- 예전 연구 노트·데이터·개인 설정은 덮어쓰거나 공유하지 않는다.
- 문서 작업이므로 코드 단위 테스트 대신 경로·내용·출처·복사본을 직접 검증한다.

## 검증 기록

- 기존 진입 문서 12개의 원래 본문을 HEAD와 비교해 보존 확인. 개인 설정의 기존 본문도 보존 확인.
- 새 기획·조사 문서 13개 링크·날짜·인코딩 확인.
- 공유용 복사본 12개 바이트 일치와 공유본 내부 링크 확인.
- 별도 검토자의 문서 검토에서 Critical/Important 지적 없음. 근거 줄 번호는 반영함. 기존 연구 경로를 공유본에 추가하지 않고 새 공식 출처 모음을 기준으로 둠.
- 문서 기획만 수행. 앱 개발·제휴·외부 업로드·커밋은 수행하지 않음.
