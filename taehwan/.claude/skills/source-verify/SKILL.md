# 출처 다시 확인 (source-verify)

- 근거: 이 폴더에서 실제로 한 방법 그대로다. 예: `research/2026-11-13-광안리-불꽃축제-검증.md`(검증본 + 2026-11-19 보강 절), `research/2026-11-12-busan-cafe-share-by-district.md`(2026-11-19 보강 절)
- CLAUDE.md 4절 규칙이 이 스킬보다 먼저다.

## 순서 (한 번에 노트 하나)

1. **고를 줄 정하기**: 노트에서 숫자·날짜·인명·인용이 있는 줄과 `[확인 필요]` 줄을 모은다. 무엇을 확인할지 사용자에게 먼저 목록으로 보여 준다.
2. **다른 노트에 답이 있나 먼저 본다**: `research/`에서 같은 사실을 찾는다(Grep). 있으면 그 노트의 URL을 쓰되, **그래도 페이지를 다시 연다.** 다른 노트에 적혀 있다는 것만으로 옮기지 않는다.
3. **페이지 열기**: web-fetch로 연다. 서로 관계없는 URL은 한꺼번에 연다.
   - 막히면(403·빈 본문) 크롬으로 한 번 더 연다 (`browser-token-saving` 메모: 글자 읽기 먼저).
   - 그래도 안 되면 다시 보내지 않고 `[확인 필요: 페이지 원문]`으로 둔다. 검색 요약은 원문이 아니다.
4. **원문 옮기기**: 문장을 **글자 그대로** 옮긴다(맞춤법 틀림도 그대로). 함께 적는 것: 제목, 발행처(기자), 발행일, URL, 확인일(오늘 YYYY-MM-DD).
5. **판정하기**: 줄마다 아래 중 하나.

| 판정 | 뜻 | 글에 쓰는 법 |
|---|---|---|
| 일치 | 독립된 두 출처가 같은 값 | 그대로 쓴다 |
| 한 출처 | 한 곳에만 있음 | "○○ 보도에 따르면" |
| 다름 | 출처마다 값이 다름 | **둘 다** 적고 고르지 않는다 |
| 원문 없음 | 페이지에 그 문장이 없음 | 빼거나 `[확인 필요: 무엇]` |
| 못 엶 | 페이지가 안 열림 | `[확인 필요: 페이지 원문]` |

   - **독립 출처 세는 법**: 같은 기관의 다른 페이지, 또는 "부산시는 …"처럼 같은 발표를 옮긴 기사 여러 개는 **독립 출처 하나**로 센다.
   - 예상·계획 문장("몰릴 것으로 예상", "배치한다")과 결과 문장("집계됐다", "했다")을 섞지 않는다.
   - 숫자는 반올림하지 않는다. "120만 5951명"과 "120만여명"은 다른 표기이니 둘 다 적는다.
6. **적기**: 원래 문장은 지우지 않는다. 노트 맨 아래에 `## YYYY-MM-DD 보강` 절을 붙이고, 원래 요약 줄 밑에는 "(YYYY-MM-DD 보강) … 아래 보강 절을 보세요" 한 줄만 단다.
7. **보여 주고 커밋**: 무엇을 채웠고 무엇이 남았는지 사용자에게 표로 보여 준 뒤 커밋한다.

## 보강 절 틀

```markdown
## YYYY-MM-DD 보강

- 확인한 날: YYYY-MM-DD. 위 절들은 (처음 확인한 날) 그대로 두고 고치지 않았다.

### 더한 출처

| 번호 | 제목 | 발행처 | 발행일 | URL | 확인일 |
|---|---|---|---|---|---|

### 채운 빈칸

| 원래 줄 | 원문 문장(그대로) | 출처 | 메모(판정·한 출처 표기) |
|---|---|---|---|

### 아직 못 채운 것

- 
```

## 하지 않는 것

- 기억이나 일반 지식으로 빈칸을 채우지 않는다. "제 일반 지식"이라고 적힌 줄도 출처를 찾아 바꾸거나 그대로 둔다.
- 한 출처뿐인 말을 사실처럼 단정하지 않는다.
- 회사·기관이 밝히지 않은 이유를 사실처럼 쓰지 않는다 ("가설:"로).
