# 한장메뉴 (가칭) 글쓰기 스킬

근거 파일: `brand/persona.md`, `brand/worldview.md` (2026-11-24). **사실 규칙이 말투보다 먼저다.** 확인되지 않은 것을 확인된 것처럼 쓰지 않는다.

## 톤 (말투 규칙)

- 존댓말. 짧게. 시장 골목처럼 따뜻하게. [제안]
- 쉬운 말: "메뉴판", "사진", "옮겨 드려요". 어려운 말(플랫폼 고도화·디지털 전환·솔루션)은 쓰지 않는다. [제안]
- 점주가 주인공이다. 도구는 돕는 쪽으로만 말한다. [제안]

## 핵심 메시지 셋 [제안]

1. "사진 한 장만 찍어 주세요. 나머지는 저희가 옮겨 드려요."
2. "메뉴판은 저희가 옮기고, 맞는지는 사장님이 정해요."
3. "외국인 손님이 메뉴를 알고 시킬 수 있게."

## 금칙어 후보 (다섯까지 · [사람이 정함])

| 후보 | 까닭 |
|---|---|
| "부산시 공식", "부산올랭 제휴" | 그런 사실이 없다 (`CLAUDE.md` 2026-11-24 절) |
| "매출 ○배", "손님 ○명 증가" | 근거 숫자가 없다 (`brand/persona.md` 말하지 않는 말) |
| "완벽한 번역", "AI가 다 알아서" | 사람이 확인하는 자리를 지운다 (`brand/persona.md` 약속) |
| "알레르기 걱정 없음", "원산지 보장" | 점주 확인 전에는 보장할 수 없다 (`LOCAL.md` 쓰지 않는 말) |
| "디지털 못하는 어르신" | 점주를 낮추는 말 (`brand/worldview.md` 뺀 것) |

## 예시 문장

- 좋은 예 [제안]: "사장님, 메뉴판 사진 한 장이면 영어·중국어·일본어 메뉴가 나와요. 맞는지 한 번만 봐 주세요."
- 좋은 예 [제안]: "부산시 조사에서 QR을 둔 가게는 34.8%였어요. 붙이기 쉬운 카드로 만들어 드릴게요."
- 나쁜 예: "부산시 공식 AI 메뉴판! 매출이 두 배로!" (금칙어 둘, 근거 없는 숫자)
- 나쁜 예: "어르신도 쉽게, 완벽한 번역으로 걱정 끝." (점주를 낮춤, 확인 자리를 지움)

## 글을 다 쓴 뒤 확인할 것

1. 숫자마다 위 '사실로만 쓸 것' 표에 있는가? 없으면 지우거나 [확인 필요]
2. 금칙어 후보가 들어갔는가?
3. 점주가 확인하는 자리가 글에 남아 있는가?
4. [제안]으로 남은 말투·설정을 사실처럼 썼는가?

## 재료 규칙 (2026-11-24 더함 · 사실 규칙)

- 재료는 사장님이 확인하기 전에는 **후보**다. 글에 쓸 때는 "보통 이런 재료가 들어가요 (사장님 확인 전)"처럼 쓴다.
- 사장님이 확인한 재료만 "사장님 확인함(날짜)"을 붙여 쓴다.
- 알레르기·종교·채식에 대해 "걱정 없음", "안전", "보장"을 쓰지 않는다. "사장님께 물어보세요"로 남긴다.
- 값은 쓰지 않는다. "값은 사장님께 물어보세요 / Ask for today's price".
- 좋은 예 [제안]: "곰장어구이 · 재료: 곰장어, 고추장 양념 (사장님 확인 전) · 매워요 · 값은 사장님께 물어보세요"
- 나쁜 예: "알레르기 걱정 없는 안전한 메뉴! 15,000원" (보장하는 말, 자료에 없는 값)
- (2026-11-24 더함) 이미 하는 곳을 낮추지 않는다. 부산올랭·파파고·음식 관광 누리집은 "함께 쓰는 도구"로만 말한다. 우리 말: "그 가게 음식에 실제로 무엇이 들었는지는 사장님이 확인해요."
- (2026-11-24 더함) 피할 재료 표시는 식약처 알레르기 유발식품 목록에서만 고른다 (정책브리핑 2021-07-14, 19개 항목 / 페이지 표기 22종).
