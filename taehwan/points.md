## 가설마다 확인할 곳 (사람이 적기)

| 가설 | 무엇을 보면 확인되나 |
|---|---|
| 2단계: 다른 지역 계류비·이동비가 든다 | 선주 인터뷰 "수영만이 닫힌 뒤 배를 어디에 두셨어요?" + 계류 노트 기사 원문 대조 |
| 3단계: 값을 정할 기준이 없다 | 판매자 인터뷰 "희망가를 어떻게 정하셨어요?" + 국내 매물 가격 모으기 (사이트 약관 확인 뒤) |
| 4단계: 사기를 당하면 억 단위 | 국내 요트 매매 사기 판결·신고 건수 (해양경찰청 정보공개 청구) |
| 5단계: 매수인이 검사원을 따로 구한다 | 매수인 인터뷰 "사기 전에 배 상태를 누구에게 봐 달라고 하셨어요?" |
| 6단계: 매수인이 한 명뿐이다 | 지역별 소유권 이전 건수 (공공 자료 또는 정보공개 청구) |
| 8단계: 등록·압류 확인을 혼자 찾는다 | 매수인 인터뷰 + 시·군·구 등록원부 열람 방법 [확인 필요] |
| 9단계: 증거 모으는 법을 모른다 | 피해 사례 기사·판결 + 경찰청 신고 안내 |
| 돈: 2%로 비용을 감당하나 | 검수원 1회 인건비, 결제사 수수료 문의 |
