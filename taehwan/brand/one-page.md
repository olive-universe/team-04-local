# 한 장 기획서 · 한장메뉴 (가칭)

- 확인한 날짜: 2026-11-24 · 쓴 스킬: `hanjang-menu-taehwan`
- 읽은 파일: `brand/persona.md`, `brand/worldview.md`, `inventory/top3.md`

> **남포동 국밥집 사장님이 외국인 손님을 받기 전에 메뉴판 사진 한 장만 찍으면, AI가 4개 국어 메뉴와 음식 설명, 테이블용 QR 카드를 만든다.**

| 칸 | 내용 |
|---|---|
| ① 누구를 위한가 | 국제시장·자갈치시장 근처에서 혼자 식당을 하는 60대 사장님 한 사람 [창작, `brand/persona.md` 고객 페르소나]. 아직 만나 보지 않았다 |
| ② 문제와 근거 | 문제 하나: 가입해도 외국어 메뉴판을 만들지 못한다. 원문 "특히 디지털 기기 이용이 익숙하지 않은 고령의 점주는 플랫폼 가입을 하더라도 외국어 메뉴판 제작 등 활용은 어렵다." (국제신문 2026-05-11, 부산시 분석 · `research/2026-11-24-주제후보-제미나이-검증.md`) |
| ③ AI가 하는 일 | 사장님이 하던 '메뉴판을 외국어로 옮기기'를 AI가 대신한다: 사진 읽기 → 한·영·중·일 메뉴 → 음식 설명 → 인쇄용 QR 카드 시안 |
| ④ 쓰는 자산과 데이터 | M10 부산올랭(문제 근거) · M01 국제시장 · M02 자갈치시장(`inventory/top3.md`). 권리: 사장님 메뉴판 사진은 사장님 동의를 받고 쓴다. 부산올랭 이름·화면은 쓰지 않는다 |
| ⑤ 사람이 확인할 곳 | 음식 설명과 재료(알레르기·원산지)는 사장님이 반드시 확인한다. 숫자는 스킬의 '사실로만 쓸 것' 표에 있는 것만 |
| ⑥ 잘 됐는지 볼 숫자 | 우리가 셀 수 있는 것만: 카드를 만든 가게 수 · 사장님이 고친 설명 줄 수 · 실제로 붙인 카드 수. 매출·손님 수는 [확인 필요] |
| ⑦ 처음 만들어 볼 가장 작은 것 | 사장님 한 분의 메뉴판으로 만든 **테이블 카드 1장** (4개 국어 메뉴 + 음식 설명 + QR). 그 밖의 기능은 넣지 않는다 |
