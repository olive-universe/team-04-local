## 표기 (모든 줄에 단다)

- **[사실]**: 파일 원문을 글자 그대로 옮긴 것 + 파일 이름 (+ 원 출처 URL)
- **[각색]**: 사실에 우리가 덧붙인 것. 바탕이 된 [사실]을 함께 적는다
- **[창작]**: 자료에 없는 것. 무엇에서 착안했는지 적는다
- [각색]·[창작]은 모두 **[제안]**이다. 사람이 고르면 **[채택: 누구 날짜]**로 바꾼다.
- 한 출처뿐인 말은 "○○ 보도에 따르면", 값이 둘이면 둘 다, URL이 우리 폴더에 없으면 `[확인 필요: URL]`.
- 후기를 쓴 사람의 닉네임은 적지 않는다 (`collection-rules.md` 공통 '뺄 것'). "VELTRA 후기(2024/11/09 참가)"처럼 사이트와 날짜로 가리킨다.
