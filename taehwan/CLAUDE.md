## 4. 할루시네이션 방지 규칙 (지우지 마세요)

- 숫자·날짜·인명·인용에는 반드시 출처 URL을 붙입니다. URL이 없으면 쓰지 않습니다.
- 직접 열어 확인하지 못한 내용은 `[확인 필요: 무엇]`으로 표시합니다.
- 한 출처에만 있는 주장은 "○○ 보도에 따르면"이라고 출처를 밝혀 씁니다.
- 회사가 밝히지 않은 이유는 사실처럼 쓰지 않고 "가설:"로 씁니다.
- 리서치 결과는 채팅 답으로 끝내지 말고 `research/` 폴더에 노트 파일로 저장합니다.
- 노트에는 확인한 날짜(YYYY-MM-DD)를 적습니다.
- inputs/ 숫자는 파일 값 그대로 쓰고 반올림하지 않는다.
- 두 출처의 숫자가 다르면 둘 다 적고 어느 쪽인지 고르지 않는다.
- (2026-11-19 더함) 확인해 둔 노트를 다시 고칠 때는 원래 문장을 지우지 않고, 아래에 `## YYYY-MM-DD 보강` 절을 붙여 더한 것만 적는다.
- (2026-11-19 더함) 브랜드·세계관 글은 줄마다 [사실](파일 원문 그대로 + 파일 이름) / [각색](사실에 덧붙임) / [창작](자료에 없음)을 단다. [각색]·[창작]은 [제안]이고, 채택은 사람이 한다.
- (2026-11-19 더함) 게이트 보류 자산(A07·A09·A14·A15·A16·A18·A19·A20·A21·A31)과 이미 다른 곳에서 쓰는 이름·캐릭터는 브랜드·세계관 글에 쓰지 않는다. 목록은 `brand/persona.md` 맨 위 '뺀 것'을 따른다.

## 5. 폴더 규칙

- 프롬프트에 폴더 없이 파일 이름만 있으면 맨 위(llm-academy/)에 저장한다.
- 프롬프트가 파일 이름만으로 기존 파일을 읽으라고 하면, 맨 위에 없을 때 `refactor-log.md`를 보고 옮긴 자리에서 찾는다.
- 자산 표는 `assets/`, 데이터 명세는 `specs/`, 리서치 노트는 `research/`, 브랜드·페르소나·세계관은 `brand/`, 쓰지 않는 옛 파일은 `old/`에 둔다.
- `archive/`는 정리본 자리다: 원본(`raw/`)을 새 이름으로 복사한 파일은 `archive/files/`(git에 올리지 않음), 그 표는 `archive/metadata.csv`.
