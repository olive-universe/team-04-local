## 3. 태환용 · 저장소가 두 개예요

| 이름 | 어디 | 무엇 | GitHub 연결 |
|---|---|---|---|
| **내 작업 폴더** | `Documents/llm-academy` | 평소 작업하는 곳. 여기서 고치고 커밋 | ❌ 없음 (실수로 팀 저장소를 덮지 않게 일부러 뺌) |
| **팀 저장소 복사본** | `Documents/team-04-local` | GitHub 팀 저장소를 내려받은 것. 올릴 때만 씀 | ✅ `origin` = olive-universe/team-04-local |

### 팀 저장소에 올리는 순서 (매번 이 순서로)

1. **내 폴더에서 커밋:** `llm-academy`에서 고친 파일을 커밋한다.
2. **팀 저장소 최신으로 받기:** `team-04-local`에서 `git pull`. 팀원이 올린 걸 먼저 받는다.
3. **팀 쪽이 더 새로운지 확인:** 내가 올릴 파일이 팀 쪽에서 바뀌었으면 덮어쓰지 말고 먼저 비교한다. (예: 2026-11-16 `TourClient.luau`는 팀 쪽이 더 새로워서 팀 버전을 내 폴더로 가져옴)
4. **복사:** 고친 파일을 `team-04-local/taehwan/` 같은 자리로 복사한다.
5. **커밋 · 푸시:** `team-04-local`에서 커밋하고 `git push`.

> Claude에게 "커밋하고 팀 저장소에도 올려줘"라고 하면 1~5를 대신 해 줘요.

## 5. 깃 말 뜻풀이

| 말 | 뜻 |
|---|---|
| 저장소 (repository) | git이 기록을 관리하는 폴더 |
| 커밋 (commit) | 지금 상태를 기록 한 칸으로 저장하기 |
| 푸시 (push) | 내 커밋을 GitHub에 올리기 |
| 풀 (pull) | GitHub의 새 커밋을 내 PC로 받기 |
| 원격 (remote, origin) | 연결된 GitHub 저장소 주소 |
| `main` | 기본 줄기(브랜치) 이름 |
| `.gitignore` | git이 무시할(올리지 않을) 파일 목록 |
