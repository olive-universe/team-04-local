## 3. 데이터 화살표마다 누가 먼저 갖나

| 화살표 | 데이터 | 누가 먼저 갖나 |
|---|---|---|
| F3 | 가입 정보 | 부산시 (부산올랭) |
| F4 | 외국어 메뉴판 | 부산시 플랫폼 (점주가 쓰지 못하면 생기지 않음) |
| F5 | 메뉴판 사진 | 점주 → 우리 도구 (가설) |
| F6 | 4개 국어 메뉴·음식 설명 | 우리 도구 (가설) |
| F7 | QR로 본 메뉴 | 부산올랭 또는 우리 도구 [확인 필요: 조회 기록을 누가 볼 수 있나] |
| F8 | 주문 | 점주 (가게 안에서 생김) |

- **우리 손을 떠나는 화살표:** F8 주문과 F10 밥값. 손님이 실제로 주문했는지, 돈을 얼마 냈는지는 가게 안에서 생겨서 우리가 바로 볼 수 없다. 가설: 도구가 주문을 도왔는지 보려면 점주에게 직접 물어야 한다.
