## 오후에는 우리 장소 리뷰로, 두 가지를 받아 봅니다

### ① 우리 팀 리뷰 분석 리포트

- 재료: 카카오맵 광안리해수욕장 후기 **30~50건**
- 결과: **차트 1장 + 인사이트 3가지**
- 저장할 곳: `report/` 폴더 (예: `report/2026-11-16-광안리-후기-리포트.md`)
- 볼 것 (예시 질문)
  - 후기에서 불꽃축제 이야기가 얼마나 나오나? (축제 / 야경 / 바다 / 맛집 / 교통·주차 / 혼잡)
  - 좋았다는 말과 불편했다는 말은 각각 무엇에 몰려 있나?
  - 축제가 있는 달의 후기는 다른 달과 무엇이 다른가?

### ② 디지털 필드워크 계획서

- 리포트로 **못 채운 빈칸**을 **어디서 · 누가 · 얼마나** 더 모을지 정하기
- 저장할 곳: 맨 위 `fieldwork-plan.md` (2026-11-16 광안리 버전으로 새로 씀. 허심청 버전은 `archive/2026-11-16-fieldwork-plan-허심청.md`로 옮김)
- 빈칸 예시 (리포트 결과를 보고 고치기)

| 빈칸 (리포트로 못 채운 것) | 어디서 | 누가 | 얼마나 |
|---|---|---|---|
| 축제 당일 관람객의 진짜 불편 (자리·교통·화장실) | 네이버 블로그 축제 후기 | | 10건 |
| 외국인 관광객 반응 | 구글맵 영어 리뷰 · 유튜브 영상 | | 30건 · 3편 |
| 축제 날 주변 가게(상가) 이야기 | 지역 커뮤니티 · 뉴스 | | 5건 |
| 공식 관람 안내·교통 통제 | 부산불꽃축제 공식 자료 · 부산시 | | 공식 자료 2건 |

> '누가' 칸은 팀이 직접 이름을 씁니다.
