- 방법: GitHub 공개 검색 API로 저장소 이름·설명을 검색했다(로그인 없음). 영어 6개("hackathon winner travel / tourism / wellness / mental health", "hackathon 1st place travel", "devpost winner travel"), 한국어 4개("TourAPI 공모전", "관광데이터 수상", "해커톤 대상", "부산 해커톤"). 영어 검색 일부는 한도 초과로 실패해 다시 돌렸다. 고른 저장소 5개는 README를 직접 열었다.

## 0. 먼저 알아 둘 것

- **"우승", "수상"은 저장소 주인이 README나 설명에 직접 쓴 말이다.** 대회 주최 측의 공식 결과 페이지는 열어 보지 않았다. 그래서 아래 표에는 모두 "○○ README에 따르면"으로 적는다.
- **아래 5개는 GitHub API에서 라이선스가 '없음'으로 나왔다**(라이선스 파일을 찾지 못했다는 뜻). 라이선스가 없으면 코드를 복사해 쓸 권리가 따로 주어지지 않는다. **아이디어와 화면 구성만 참고하고, 코드는 가져오지 않는다.**
- 별(star) 수는 0~7개로 적다. 많이 쓰이는 도구가 아니라 학생·팀 프로젝트다.
