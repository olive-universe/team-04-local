# 웰니스 기업 후보 조사 · 점검 기록

확인일: 2026-11-23

## 적용 범위

사용자가 제공한 회사 후보 조사 안내문을 부산 웰니스 주제로 바꾸었다. 광안리 우선 조건은 철회하고, 기업을 배우는 조사와 최적 코스를 고르는 조사를 구분했다.

- [최신 조사 기준](../wellness/industry/company-pick-brief.md)
- [예비 후보 셋과 출처](../wellness/industry/company-pick.md)

사업 관련성으로 씨제이올리브영, 아난티, 파라다이스호텔부산을 예비 후보로 정리했다. 같은 법인의 DART 재무 공시 원문 확인까지 끝난 후보는 없다. DART 접근 실패를 공시 부재로 해석하지 않았다.

## 원문 확인 범위

- 회사명 확인용 KISA 공시는 재무 감사보고서가 아니다.
- 아난티 코브 공식 시설 소개는 서비스 접점을 확인하는 자료이며 시설별 운영법인·연결 범위를 확정하는 재무자료가 아니다.
- KIND에서 직접 읽은 문서는 파라다이스호텔부산 자체 보고서가 아니라 모회사 ㈜파라다이스의 2025년 사업보고서다.
- 기사 원문 셋은 직접 열어 짧게 인용했다. 모두 회사 발표·프로그램 소개 성격으로, 독립적인 사업 성과 검증 자료라고 쓰지 않았다.
- 파라다이스호텔부산의 오니스트 패키지는 2026-10-31까지였으므로 종료된 참고 사례로 표기했다.
- 이번 조사에서 구글맵 위치·거리·경로·리뷰는 직접 검증하지 않았다.

## 점검해 보완한 것

1. 주제 관련성을 공시 유무보다 먼저 판단하도록 변경.
2. 실제 저장 경로 지정, 산업 선택란이 비어 있을 때 임시 범위와 최종 선택 구분.
3. 법인·브랜드·시설·모회사 구분, 공시 문서 종류·사업연도·정정 여부 확인.
4. 최근 1년의 날짜 범위, 기사 입력일, 원문 열람, 짧은 인용과 해석 구분.
5. 다른 지역 프로그램·종료된 프로그램·미체결 제휴를 현재 부산 운영으로 오해하지 않도록 조건 추가.
6. 자료 부족과 접속 실패를 표시하고, 확인된 후보 수와 예비 후보 수를 분리.
7. 원본 보존·공유용 복사본 원칙 유지.
