## 2. 잘된 것 (Keep)

- **원본은 고치지 않고 따로 뒀다.** `inputs/kakao-raw.txt`는 읽기만 했고, `.gitignore`로 막아서 팀 저장소에 올라가지 않게 했다.
- **근거 문장을 원문 그대로 썼다.** `tagged.csv`의 근거 문장은 스크립트로 원문에 글자 그대로 있는지 하나씩 확인했다.

- **팀 저장소 구조를 먼저 봤다.** 팀원마다 이름 폴더를 쓰는 걸 확인하고 `taehwan/`에만 올렸다. 팀 쪽이 더 새로웠던 `TourClient.luau`는 덮어쓰지 않았다.

## 3. 막혔던 것과 배운 것 (Problem → Learn)

| 막혔던 것 | 어떻게 풀었나 | 배운 것 |
|---|---|---|
| 프롬프트의 `○○○` 칸을 안 채운 채로 보냄 (여러 번) | 장소·목적을 광안리로 채워서 진행 | 프롬프트를 붙여 넣기 전에 `○○○`부터 채운다 |
| 첫 번째 복사본이 **유용한 순과 최신순이 섞여** 있었음 | 최신순으로 다시 복사. 첫 복사본은 `archive/`로 | 복사하기 전에 정렬 버튼 글자를 한 번 확인한다 |
| 두 번째 복사본은 20건뿐 | 더보기를 더 눌러 120건 | 50건쯤 보이는지 스크롤 끝에서 확인한다 |
| 후기별 **별점이 복사되지 않음** | 별점 칸을 빈칸으로 두고 리포트에 "말할 수 없는 것"으로 적음 | 통째로 복사하면 별(그림)은 글자로 안 남는다 |
| 허심청(온천)용 기준표가 광안리에 거의 안 맞음: 78건 중 11건 | 새 태그 후보 8개로 따로 모음 | 장소가 바뀌면 태그 기준표도 새로 만들어야 한다 |
| 허심청용 낱말 지표가 대부분 0 | 낱말 규칙 값과 사람이 읽은 값을 둘 다 적음 | 낱말 세기는 사투리("부산아이가!")나 활용형("비쌉니다")에 틀린다 |
| git 저장소가 OneDrive 폴더 전체를 잡고 있었음 | `llm-academy`만 따로 저장소로 만들고, 바깥 `.git`은 지움 | git을 시작할 때 `git rev-parse --show-toplevel`로 범위부터 본다 |
| 계획서가 수업 기준표("한 줄 = 소스 하나 · 담당 한 사람")와 달랐음 | 카카오맵 줄 빼고, 확인할 것을 질문 한 줄로 줄임 | 다 쓰고 나서 수업 기준표에 한 줄씩 대 본다 |
