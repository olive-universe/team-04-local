# 한 장 기획서 · 부산 바다 감각 산책

기준일: 2026-11-23 · 현장·고객 검증 전

> [제안] 부산 여행객이 바람·파도·해안길을 직접 느끼고, 따뜻한 맛과 선택형 손 관리 활동으로 마무리하는 소규모 150분 프로그램.

| 항목 | 현재 설계 |
|---|---|
| 중심 | 사용자가 선택한 부산의 공간감과 바다 |
| 첫 고객 | [검증 전 가설] 영어 진행이 가능한 성인 외국인 개별 여행객. 한국어 리허설을 먼저 진행 |
| 지역 | [제안] 기장 오시리아를 첫 답사 후보로 설정. 광안리 제약은 없음. 부산 전체 최적지 검증 전 |
| 장소 근거 | 기장군이 소개한 약 2.5km의 연결 산책로 [S4](sources.md). 실제 정지점·거리·시간·출입은 미확인 |
| 고객 문제 | [검증 전 가설] 바다를 보고 지나가는 일정에서 잠시 천천히 몸으로 경험할 시간을 만들기 어렵다 |
| 활동 | [제안] 바람 느끼기·파도 소리 듣기·정규 길 걷기 → 실내 차·작은 음식 → 선택형 손 관리·감각 회고 |
| 유료 가치 | [검증 전 가설] 소규모 진행·다국어 안내·활동 구성·확정 실내 자리·식음·귀가 후 콘텐츠. 바다 입장료를 받는 것이 아님 |
| 인원·시간 | [제안] 최대 8명, 진행자·후방 운영자 각 1명, 09:30~12:00. 실제 리허설 전 |
| 가격 | [모의 가정] 1인 79,000원. 실제 판매가·견적 아님. [비용안](pilot-budget.md) |
| 별도 비용 | 교통·정규 점심·스파·개인 쇼핑. 스파는 기본 가격·시간에 미포함 |
| 네 분야 | 콘텐츠는 감각 안내, 푸드는 맛·온기, 뷰티는 자율 관리 체험, 리테일은 경험 후 선택형 구매 |
| 수익 | [검증 전 가설] 초기에는 참가비로 운영 가능성 확인. 판매·협업 수입은 후속 가설이며 기준 예산에 미포함 |
| AI | 활동 카드·번역·피드백 정리 초안. 현장·효능·운영 가능성을 대신 판정하지 않음 |
| 사람 | 동선 답사·안내·공간·식음·제품 조건·언어·현장 대응 검증 |
| 현재 상태 | 공식 자료 기반 설계. 현장·실내 거점·협의·실제 비용·고객 수요 미확인. 모집 전 |

상세 운영은 [프로그램](sea-program.md), [파일럿](pilot-operations.md)을 따른다. 기존 장소 추천·예약 링크 중심 초안은 이 프로그램을 돕는 정보 기능으로 위치를 바꾼다.
