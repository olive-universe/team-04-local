# 바다 감각 산책 · 첫 파일럿 운영안

기준일: 2026-11-23 · 모두 준비·실험 계획이며 실행된 결과가 아님

## 현재 상태

공식 관광·운영 자료를 읽고 프로그램을 설계했다. 지도 경로 검증·현장 답사·공간 협의·운영자 섭외·보험/유료 운영 조건 확인·고객 모집·결제는 아직 하지 않았다.

## 1단계 · 후보 구간과 거점 확인

| 할 일 | 기록할 결과 | 다음으로 갈 기준 |
|---|---|---|
| 공식 안내와 지도 비교 | P0~P4 후보의 지도 URL·주소·좌표·공공/시설 구분 | 구간의 실제 연결과 출입 조건을 확인 |
| 같은 시간대 직접 걷기 | 실제 걸린 시간, 멈춘 시간, 거리, 계단·노면, 소음·혼잡·바람, 쉬는 자리 | 150분 안에서 참가자에게 맞는 활동·휴식 배정 가능 |
| 시작·끝·중간 이탈 확인 | 화장실·실내 대피·해산 뒤 이동수단·연락 방법 | 각 지점을 운영자가 설명할 수 있음 |
| 관리 주체 확인 | 상업적 단체 프로그램·정지 활동·표지물·소리 재생 등의 이용 조건 | 필요한 협의·허용 조건을 확인. 공공 길이라고 자동 허용으로 가정하지 않음 |
| 실내 후보 협의 | 수용 인원, 예약 보장, 대관/주문 조건, 최소 주문, 취소, 음식·용품 사용, 화장실 | 운영 시간에 맞춰 자리가 보장되고 예산을 계산할 수 있음 |

산책로와 실내 거점 조건 중 하나라도 불충분하면 후보 구간을 줄이거나 다른 권역을 비교한다. ‘오시리아로 정했으니 강행’하지 않는다.

## 2단계 · 현장 리허설 [목표]

- 한국어로 성인 참가자 4명을 대상으로 무상 또는 실제 재료비만 드는 리허설을 제안한다. 외부 모집·연락·비용 수납을 실행한 상태는 아니다.
- 진행자·후방 운영자 역할을 나누고 150분 진행표를 실제로 실행한다.
- 고객이 원하지 않는 대화·촬영·제품 사용을 하지 않을 수 있게 한다. 눈을 감고 이동하거나 파도에 가까이 다가가는 지시를 하지 않는다.
- 제품 사용·식음 제공은 합의한 장소와 제공자가 맡는다. 가정한 메뉴·제품을 임의로 현장 반입하지 않는다.
- 영어 진행문은 원문을 아는 검수자가 확인하고, 실제 안내 속도로 읽어 소요시간을 다시 잰다.

## 3단계 · 초기 수요 확인 [목표]

첫 대상은 영어 진행이 가능한 외국인 개별 여행객이다. 직접 운영에 앞서 인터뷰와 프로그램 카드 반응을 먼저 확인한다. 모집 경로 후보는 동의를 얻은 숙소 안내·지역 체험 운영자·자체 콘텐츠다. 제휴나 고객 유입이 확보된 것은 아니다.

### 보여 줄 것

한 장 소개: 장소와 일정, 실제 하는 활동, 확인된 보행 조건, 포함·별도 항목, 모의 가격 79,000원. 가격을 물을 때 모의안임을 명시하고 아직 결제·예약을 받지 않는다.

### 고객에게 물을 것

1. 이번 여행에서 바다 근처에서 실제로 무엇을 했는가?
2. 혼자 걷기와 비교해 이 프로그램에서 필요하거나 불필요한 부분은 무엇인가?
3. 150분 중 가장 기대되는 활동과 빼고 싶은 활동은 무엇인가?
4. 79,000원이라는 모의 가격을 보고 참여할지, 무엇 때문에 결정이 달라지는지?
5. 언어·이동·식음·일정 중 참여를 막는 조건은 무엇인가?

‘좋다’는 응답, 참여 의향, 실제 신청, 실제 결제·방문을 각각 구분한다. 소수 인터뷰를 관광객 전체의 수요 비율로 발표하지 않는다.

## 4단계 · 유료 회차 검토

보행·거점·실제 비용·운영 책임·취소/환불·관할 확인사항을 정리한 후 유료 회차를 검토한다. 현재는 출시 전이다. 모의 비용만 맞는다고 판매하지 않는다.

## 최소 준비물 [제안]

확인된 동선표, 한 언어 감각 카드, 참가자 수와 연락 가능한 운영자, 물·휴식 안내, 날씨에 맞는 안내, 실제 공간 확인 기록, 식음·제품 제공 합의, 익명 피드백 양식. 음향 장비·음악 재생·대형 설치물은 기본안에 필요하지 않다.

개인정보가 담긴 파일은 공유 대상에서 제외하고 파일명·내용도 언급하지 않는다. 외부 공개 자료에는 익명 집계와 동의받은 공개용 내용만 사용한다. 사진·음성 기록 참여는 프로그램 참여와 별개로 선택하게 한다.
