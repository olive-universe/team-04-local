# 광안리에서 부산 웰니스로 · 전환 기록

전환일: 2026-11-23

## 사용자가 정한 것

부산 웰니스로 주제를 바꾸고, 기존 광안리 기획에서 살릴 부분은 살린다. 푸드·리테일·콘텐츠·뷰티 연결을 고려한다. 세부 선택은 최선의 판단으로 진행한다. 원본은 보존하고 외부 공유에는 복사본을 쓴다.

## 이번에 판단한 것

| 구분 | 결정 | 이유 |
|---|---|---|
| 첫 고객 [제안] | 외국인 개별 여행객 | 이용 안내·언어·예약 연결 가치를 검증하기에 적합한 가설. 우월한 수익성이 검증됐다는 뜻은 아님 |
| 시작 지역 [제안] | 광안리 | 기존 지역 맥락과 조사 경험을 재사용할 수 있음 |
| 첫 상품 [제안] | 반나절 코스 안내와 외부 예약 연결 | 시설 조성 전에 고객 선택 행동을 확인할 수 있음 |
| 대안 | 주민 멤버십은 후속 검증 | 반복 이용과 재방문 가치를 먼저 확인해야 함 |
| 공간 확장 | 기장 해안권은 별도 검토 | 후보지·이동·운영·사업성이 확인되지 않음 |
| 브랜드 | 새로운 작업명과 약속 | 불꽃 관람 중심 이름·캐릭터를 새 주제에 억지로 적용하지 않음 |

## 살린 것

바다·걷기·쉬는 장소, 이동과 이용 조건을 먼저 알리는 접근, 다국어 안내 방식, 출처를 단 정보 정리.

## 현재 기획에서 제외한 것

축제 당일 시간표·관람석·불꽃 시야·인파 예측, 불꽃 전용 브랜드 이름·캐릭터·갈등. ‘부산에 웰니스가 거의 없다’는 미확인 비교 주장.

## 원본과 현재 문서의 관계

- `wellness/`가 현재 기획 기준이다.
- 기존 광안리 분석·데이터·브랜드 문서는 당시 작업의 기록으로 남긴다. 과거 사실을 새 주제로 단어만 바꾸지 않는다.
- 기존 활성 문서에는 현재 기획 경로를 안내하는 머리말을 붙인다. 원래 본문은 보존한다.
- 기존 개인 설정에는 이번 주제 전환을 안내하는 새 절만 추가한다. 과거 내용에서 현재 주제를 재추론하지 않는다.
- 팀 공유에는 `team-share/busan_02/wellness/`에 준비한 새 기획 복사본만 사용한다.

## 아직 실행하지 않은 것

인터뷰·현장 조사·제휴 체결·유료 상품 판매·앱 구현·시설 유치·GitHub 업로드. 각 항목은 기획과 구분해 진행 상황을 기록한다.
