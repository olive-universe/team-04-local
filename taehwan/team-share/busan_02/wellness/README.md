# 부산 바다 감각 산책 · 현재 기획

기준일: 2026-11-23 · 작업명: 부산 바다 감각 산책 / Busan Sea Senses [제안·이름 사용 가능 여부 미확인]

> 부산의 바람·파도·해안길을 몸으로 느끼고, 따뜻한 맛과 손끝의 감각으로 마무리하는 150분. [제안]

## 현재 결정과 확인 상태

- 사용자가 선택한 중심은 **부산의 공간감을 몸으로 경험하기**, 그리고 **바다**다.
- 광안리 우선 조건은 철회했다. 첫 답사 후보는 **기장 오시리아 해안산책로**다. 부산 전체 최적지로 검증한 것은 아니다.
- 초기 상품은 안내 페이지를 넘어 **진행자가 이끄는 소규모 감각 프로그램**으로 구체화한다. 장소 안내·앱은 운영을 돕는 수단이다.
- 150분·최대 8명·진행 2명·한국어/영어 별도 회차·1인 79,000원은 기획·계산용 가정이다.
- 실제 동선·정지점·실내 거점·견적·유료 운영 조건·고객 지불 의사는 확인 전이다. 아직 예약을 받는 상품이 아니다.
- 스파·입수·해양 스포츠는 기본안에 포함하지 않는다. 스파는 조건을 확인할 선택형 확장 후보다.
