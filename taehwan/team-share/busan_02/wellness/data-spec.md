# 바다 감각 산책 · 데이터와 AI

기준일: 2026-11-23 · 앱 구현 전 운영·조사 명세

## 모을 데이터

| 묶음 | 필요한 항목 |
|---|---|
| 동선 | 정지점·지도 URL·좌표·공공/시설 구분·출입/활동 조건·측정일·측정 거리·실제 이동시간·계단/노면·쉼터·화장실·중간 이탈 |
| 환경 | 회차 시간대·날씨·파도 영향·통제·소음·혼잡·그늘·운영 중단 판단 기록 |
| 거점 | 좌석 수·예약 보장·대관·최소 주문·외부 음식/용품·화장실·취소·견적·합의 상태 |
| 식음/제품 | 실제 표시 정보·재료·원산지·알레르기 안내 경로·사용법·권리·제공 주체 |
| 콘텐츠 | 원문·출처·사실/창작·언어·번역 검수·음원/사진 권리·갱신일 |
| 운영 | 활동별 배정/실제 시간·중단·대기·제공 내역·실제 비용·인원 |
| 피드백 | 익명 번호·자유 응답·감각 기억·유료 가치·가격 반응·신청/결제/방문 구분 |

기존 리뷰와 새 파일럿 응답을 같은 표본으로 합치지 않는다. 개인정보가 담긴 파일은 공유 대상에서 제외하고 파일명·내용도 언급하지 않는다.

## AI 역할 [제안]

출처 기반 안내 카드, 한국어/영어 진행문 초안, 수집 항목 정리, 익명 피드백의 주제별 분류, 비용 산술 확인. 번역·분류는 사람이 원문과 대조한다.

AI가 현장 통제·안전·효능·실시간 좌석·가격·허용 여부를 추측해 판정하지 않는다. 필요 없는 앱·건강진단·추천 알고리즘을 먼저 만들지 않는다. 첫 결과물은 활동 카드와 운영표다.

평가와 수집 순서는 [운영안](pilot-operations.md)을 따른다.
