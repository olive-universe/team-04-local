# 마린딜러 · 5분 시연 대본 + 심사위원 예상 질문

- 작성일: 2026-11-24
- 팀: 올리브 유니버스 (혜선 · 이지 · 유진 · 태환)
- 화면: `marine-dealer/index.html` (시연), `marine-dealer/pitch.html` (비교·로드맵 한 장)
- 발표 시간은 **5분으로 가정**했다. 다르면 시간표만 줄이거나 늘린다.
- 말할 때 지킬 것: 매물·금액·점수는 **가상**, 비율·기간은 **설계 가정**, 제휴·인터뷰·실제 AI 모델은 **없음**. 묻지 않아도 먼저 말하면 오히려 신뢰가 올라간다.
- 발표자 배정은 **[제안]**: 역할(기획·검수·안전거래·AI)에 맞춰 나눴다. 팀이 바꿔도 된다.

## 0. 발표 10분 전 점검

1. 크롬으로 `index.html` 열기 → 화면 맨 아래 **'시연 데이터 초기화'** 누르기 (지난 연습 기록 지움)
2. 언어 **한국어**, 화면 배율 100%, `F11` 전체 화면
3. 바탕화면에 사기 시연용 사진 준비: `marine-dealer/assets/fraud-027.jpg` 복사해 두기
4. 인터넷 없어도 됨 (전부 이 컴퓨터 안에서 동작)
5. 비상용: 화면이 멈추면 `pitch.html`과 미리 녹화한 시연 영상으로 넘어간다 (**녹화 하나 떠 두기**)
