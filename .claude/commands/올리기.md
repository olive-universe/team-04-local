---
description: 내가 바꾼 파일을 표로 확인받고, "좋아"면 그 파일만 올린다
---
1. CLAUDE.local.md에서 내 이름과 이름 폴더를 확인한다. 없으면 멈추고 묻는다.
2. `git pull` (막히면 받기와 똑같이: 아무것도 지우지 말고 멈춤)
3. `git status`를 표로 보여 준다:
   | 파일 | 새로/고침 | 내 이름 폴더 안인가 |
   - 내 이름 폴더 밖 파일은 ⚠️ 표시하고, 따로 말하지 않으면 올리지 않는다.
   - 리뷰·자막 원본, 전화번호, 비밀번호, API 키로 보이는 것이 있으면 경고한다.
4. 여기서 멈추고 기다린다.
5. "좋아"라고 하면 표에서 확인받은 파일만 하나씩 `git add <파일>` (`git add .`, `-A` 금지)
6. `git commit -m "내 이름: 한 일 한 줄"`
7. `git push`
   - 거절(rejected)되면 `git pull` 뒤 다시 `git push`
   - 같은 파일이 부딪히면(conflict)만: 아무것도 지우지 않고(reset·--ours/--theirs 금지)
     두 판을 나란히 보여 준 뒤 합칠 안을 제안하고 답을 기다린다.
