## 키워드

안전검사, 변경등록, 등록원부, 수상레저종합정보시스템, 중고 요트 매물 채널

## 요약

해경 공식 포털에 안전검사·등록 정보는 있지만 여러 페이지에 흩어져 있고, "요트를 사고팔기만 해도 검사를 다시 받아야 하나"에는 어디에도 똑바른 답이 없다. 부산 매물 채널도 확인 절차를 알려 주지 않는다. 그래서 **공식 안내를 한 흐름으로 모아 쉬운 말로 바꾸고, 내 상황에 맞는 할 일·기한을 자동으로 뽑아 주는 도우미**가 빈자리다. [제안]

## 3. 해경 포털 안전검사·등록 안내 (2026-11-24 열람)

### 있는 것
- 검사 종류: "신규검사 : 신규 등록을 하려는 경우 실시하는 검사", "정기검사 : 신규 등록 후 일정 기간마다 정기적으로 실시하는 검사", "임시검사 : 정원 또는 운항구역, 구조, 설비 또는 장치를 변경하려는 경우 하는 검사" — https://boat.kcg.go.kr/wrls/info/wtrSfipInfo1.do
- 정기검사 주기: 개인용 5년, 사업용 1년. 만료일 전후 각 30일 안에 받으면 종전 만료일 다음 날부터 새 기간 — 같은 페이지
- 세일링요트 검사 대행기관: 한국해양교통안전공단, (사)한국수상레저안전협회. 연합회는 해수면 세일링요트를 다루지 않음 — 같은 페이지
- "지방자치단체에 따라 지정 대행기관이 다르니, 자세한 사항은 검사기관에 문의하시기 바랍니다." — 같은 페이지
- 전국 검사기관 30곳 주소·연락처 표(부산: 공단 부산지사 서구 암남동, 연합회 부산지부 수영구 민락동) — https://boat.kcg.go.kr/wrls/info/sfipAgncyInfo.do (전화번호는 공개 저장소라 옮기지 않음)
- 변경등록: "그 사유가 발생한 날부터 30일 이내", "방문", 수수료 "1,500원", 제출서류에 "안전검사증 사본" 포함, "등록관청의 판단 하에 등록조건에 따라 제출서류가 가감될 수 있습니다." — https://boat.kcg.go.kr/wrls/info/wtrAplyInfo.do
- 신규등록: "취득한 날부터 1개월 이내", 등록 원인 서류 예시 "양도증명서, 제조증명서, 수입신고필증, 매매계약서 등" — 같은 페이지
- 등록 순서: ① 안전검사 → ② 보험가입 → ③ 기구등록 → ④ 등록번호판 → ⑤ 등록증·원부 발급. 안전검사 대상 "처음으로 동력수상레저기구를 등록하는 자 또는 변경 등록을 하려는 자" — https://boat.kcg.go.kr/wrls/info/wtrAtrpOrder.do

### 없거나 헷갈리는 것
1. **"매매만 해도 안전검사를 다시 받아야 하나?"에 똑바로 답하는 문장이 없다.** 등록 순서 페이지는 "변경 등록을 하려는 자"를 검사 대상으로 적지만, 안전검사 안내 페이지의 임시검사 대상은 구조·설비 변경뿐이고 소유자 변경은 없다. 두 페이지가 다르게 읽힌다. 고르지 않음.
2. 변경등록 정의("등록증 또는 등록원부에 기재된 사항의 변경")에 "매매", "양도"라는 말이 없다.
3. 변경등록 처리기관: 포털은 "전국 시장 • 군수 • 구청장"(주소지 제한 문구 없음) / 앞선 조사 노트는 "새 소유자 주소지 구청". 다름. 고르지 않음.
4. 안전검사 수수료, 미검사 벌칙, 온라인 신청 가능 여부가 검사 안내 페이지에 없다.
5. 근거 법 이름이 페이지마다 다르다: "수상레저기구의 등록 및 검사에 관한 법률 제15조"(안전검사 안내) / "수상레저안전법 시행령 제37조"(검사증 출력, 실명인증 근거로 인용).
6. 정보가 4개 이상 페이지에 흩어져 있고, 안전검사 안내와 검사증·필증 안내(https://boat.kcg.go.kr/wrls/info/wtrSfipInfo2.do)는 내용이 거의 같다.
7. 어려운 말: 입거·상가·거선, 복원성, 해수면/내수면, 선박용 물건.

### "사람들이 잘 모른다"의 근거

## 8. MVP 범위 [제안]

| 구분 | 무엇 | 이유 |
|---|---|---|
| ✅ 넣기 | **내 상황 질문 3개 → 할 일 순서표 자동 생성**: 사는지/파는지, 개인용/사업용, 마지막 검사일·매매 예정일 → 검사 만료 D-day, 정기검사 기간(앞뒤 30일), 변경등록 기한(30일), 보험 기한(1개월), 가져갈 서류, 갈 곳(부산 기관 주소) | 흩어진 공식 안내를 한 흐름으로. 트랙의 '업무 자동화'에 맞음 |
| ✅ 넣기 | **판매자에게 받을 서류·현장 질문 목록**: 등록원부 사본(갑구·을구), 검사증, 양도증명서. 발급문서 진위 확인 안내 | 온라인 제3자 조회가 안 되므로 |
| ✅ 넣기 | **쉬운 말 풀이 + 출처·확인일 표시**: 항목마다 해경 페이지 링크. 공식 답이 없는 건 "기관에 물어보세요"로 넘김 | 법 안내는 틀리면 해가 됨 |
| △ 검토 | 부산 계류지 현황판 | 지금 가장 급한 문제지만 데이터가 기사뿐 |
| ❌ 빼기 | 소유·저당 자동 조회, 중개·에스크로, 시세 추정 | 조회 불가 / 해운법 등록 미확인 / 개별 거래 데이터 없음 |

**모아툴과 다르게 할 점 [제안]** (기한 계산은 이미 있음)
- 요트 전용: 요트조종면허, 계류지, 20톤 기준 분기
- 부산 구·군별 담당 부서·구비서류 표 + "구청마다 다를 수 있으니 미리 전화" 안내 (4-1절: 공식 안내끼리 다름)
- 사는 사람·파는 사람 둘 다 확인하는 체크리스트 (제주해경이 짚은 변경등록 미이행)
- 판매자 서류 대조 (원부 갑구·을구, 검사증 유효기간)
