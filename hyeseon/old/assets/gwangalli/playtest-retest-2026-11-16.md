# 광안리 수정 후 실제 플레이 재검사

날짜: 2026-11-16. 최종 저장: Roblox 장소 78796880132509, 버전 22. 공개 게시하지 않음.

## 발견해서 수정한 문제

- 기존 컵은 Cylinder의 긴 X축이 손잡이에 직접 붙어 옆으로 누웠다. 숨긴 손잡이와 Y축으로 세운 컵·뚜껑·빨대를 분리했다.
- 단순 IK 적용은 현재 R15의 AnimationConstraint 관절에서 입에 닿는 자세가 나오지 않았다. 최종판은 각 클라이언트의 PreSimulation에서 두 팔뼈 길이로 손 자세를 계산하고 관절 Transform에 적용한다. Motor6D와 AnimationConstraint를 모두 읽으며 RigAttachment는 변경하지 않는다.
- 컵을 단순히 몸 앞에 띄우지 않고, 손과 컵의 실제 RightGrip 연결을 유지한다. 캐릭터의 팔이 컵을 잡은 채 움직인다.
- 마시기 알림은 별도 notice 상태로 보내 다른 상점의 진행 상태를 바꾸지 않는다.

## 실제 입력으로 통과한 항목

| 항목 | 관찰 결과 |
|---|---|
| 카페 접근·입장 | 기본 속도 navigation으로 이동 후 실제 위치 오차를 확인했다. 입구를 통과해 카운터에 도착했다. |
| 주문 | E를 누르고 주문 메뉴의 라테 버튼을 마우스로 클릭했다. 음료 Tool이 지급됐다. |
| 서서 마시기 | 컵의 세운 축 Y값 약0.9998. 실제 클릭 후 34프레임 관찰에서 빨대 끝과 입의 기준점 간 최소거리 약0.072 stud. 잔량3→2, 동작 종료 후 정상 잡는 자세로 복귀. |
| 중간에 넣기 | 마시기 시작 후 0.2초에 숫자1로 넣었다. 잔량2 유지, Drinking=false. |
| 앉아서 마시기 | 실제 Seat로 걸어가 Seated 상태를 확인한 뒤 클릭. 33프레임 관찰에서 빨대·입 최소거리 약0.072 stud, 잔량2→1. |
| 빈 음료 | 마지막 모금1→0 이후 추가 클릭에도 음수나 반복 마시기 상태가 발생하지 않았다. |
| 의자에서 일어나 퇴장 | Space 후 옆으로 이동해 서 있는 상태를 확인하고 입구 밖 목표 좌표까지 걸어 나왔다. 실제 위치 오차5 stud 미만. |
| 소품샵 | 카페 밖에서 걸어가 입장하고 E·마우스로 구매. 조개 키링이 지급됐다. |
| 인형뽑기집 | 걸어서 입장해 기계 앞에서 E·Play 클릭. 집게 높이13.5→12.3→13.5 관찰. 토큰73→68. 이번 재검사 결과는 미당첨으로 정상 처리됐다. |
| 호텔 | 거리와 입구를 걸어 통과해 체크인. 루프톱 Y약68로 이동, 메뉴 자동 닫힘. 옥상 복귀 패드까지 걸어가 E로 로비 Y약6에 돌아왔다. |
| 콘솔 | 게임 코드 런타임 오류 없음. Studio 도구가 테스트용 Scriptable 카메라를 Custom으로 복귀시켰다는 안내만 있었다. |

컵 회귀검사 시작 지점은 카운터 근처로 배치한 테스트 픽스처다. 그 뒤 카페 의자·퇴장·소품샵·인형뽑기집·호텔까지의 이동은 캐릭터를 걸어서 조작하고 실제 좌표를 확인했다. 호텔의 층 이동은 게임 기능 자체의 순간 이동이다.

## 검증 범위

이번 음료 자세는 현재 사용자의 R15 캐릭터로 확인했다. 다른 신체 비율 및 R6 자세와 실물 휴대폰 터치는 추가 검증이 필요하다. 기록의 수치는 실제 장소의 치수가 아닌 게임 런타임 측정값이다.
