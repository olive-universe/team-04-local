# 광안리 로블록스 맵 참고 사진 목록 (위키미디어 공용)

확인일: 2026-11-16

## 어떻게 모았나

- 위키미디어 공용(Wikimedia Commons) API로 아래 세 분류에 들어 있는 파일 정보를 받았다.
  - Category:Gwangalli Beach (27개): https://commons.wikimedia.org/wiki/Category:Gwangalli_Beach
  - Category:Gwangan Bridge (60개까지만 받음, 더 있음): https://commons.wikimedia.org/wiki/Category:Gwangan_Bridge
  - Category:Busan International Fireworks Festival (10개): https://commons.wikimedia.org/wiki/Category:Busan_International_Fireworks_Festival
- 라이선스·작가·촬영일은 각 파일 페이지의 메타데이터(API 값)를 그대로 옮겼다. 사진을 눈으로 열어 보지는 않았다.
- 사진 파일은 내려받지 않았다. 링크만 적었다.
- 촬영일 칸이 비었거나 "Taken on…"처럼 잘린 것은 `[확인 필요: 촬영일]`로 적었다.

## 라이선스 쉬운 설명

| 표시 | 뜻 |
|---|---|
| Public domain / CC0 | 조건 없이 자유롭게 사용 가능 (그래도 출처를 적어 두는 게 좋음) |
| CC BY | 작가 이름과 라이선스를 밝히면 사용·수정 가능 |
| CC BY-SA | 위 조건 + 고쳐서 만든 결과물도 같은 라이선스로 공개해야 함. 게임 텍스처로 직접 넣을 때 주의 |
| KOGL Type 1 (공공누리 제1유형) | 출처를 밝히면 상업적 이용·수정 가능 |
| Attribution | 작가 이름을 밝히면 사용 가능 `[확인 필요: 파일 페이지의 정확한 조건]` |

참고 사진으로 보고 모양을 따라 만드는 것과, 사진 자체를 게임에 넣는 것은 다르다. 이 목록은 우선 **보고 참고하는 용도**다.
