# 광안리 맵 후속 제작 참고

확인일: 2026-11-16

## 현재 제작 상태

- Studio의 `Workspace.GwanganBridge_Blockout` 모델과 기본 바닥·스폰을 확인했다.
- 해변·바다·산책로·건물·불꽃·관광 UI는 아직 제작되지 않았다.
- 다리 가져오기 기록: `assets/gwangalli/blender/roblox_import.json`.

## 확인한 참고 자료

- 부산 관광 아카이브 「광안리해변1」: https://visitbusan.net/archive/dataSearch/view.nm?dataSid=METADATA017200&menuCd=36
- 페이지 본문에서 광안리해변 전경 사진, 제작자 수영구 기획감사실(홍보계), 발행자 부산광역시 수영구청으로 확인했다.
- 해당 사진은 페이지에 공공누리 제4유형으로 표시되어 있다. 게임에 사진을 삽입하지 않는다.
- 검색 결과의 축소 이미지와 메타데이터는 확인했으나, 원본 이미지 직접 열기는 시간 초과로 실패했다. 정확한 해안선 곡률·건물 배치·다리 거리는 아직 검증되지 않았다.

## 다음 제작 제안

기존 기획의 순서대로 해변·바다·산책로의 기본 배치를 먼저 만들고, 건물·야간 조명, 불꽃쇼·관광 기능으로 진행한다. 수치와 배치는 게임용 임시 설계값이며 실측 복원으로 표시하지 않는다.

현재 사용자의 제작 우선순위 응답을 기다리는 중이다. 이 문서는 구현 완료 기록이 아니다.
