# 팀 표 합치기 (공통 실습 · 취합 담당만, 14:40)

1. 팀 저장소 첫 화면에서 초록 **Code** 단추 → **Download ZIP**
2. 받은 ZIP을 압축 풀고(Windows: 오른쪽 클릭 → 모두 압축 풀기, Mac: 두 번 클릭), 풀린 폴더를 `llm-academy` 안에 넣습니다.
3. 아래 블록을 Claude Code에 보냅니다.

```text
llm-academy 안에 방금 받은 팀 저장소 폴더(이름이 -main으로 끝남)가 있어. 그 안의 my-assets.md 를 모두 찾아 읽고, 표 하나로 합쳐 llm-academy 맨 바깥에 team-assets.md 로 저장해 줘.
1. 먼저 어느 폴더에서 몇 줄을 가져왔는지 보여 줘(폴더 이름 = 팀원).
2. 같은 자산이 여러 줄이면 한 줄로 합치고, 담당 칸에 이름을 모두 적어. 출처가 서로 다르면 하나는 '독립 출처 URL' 칸으로 옮겨.
3. 줄의 내용(설명·출처·판정)은 바꾸지 마.
4. 표 아래에 '## 다시 찾을 줄'을 만들어, URL이 없는 줄과 판정이 '확인 못 함'·'독립 출처 없음'인 줄을 적어.
5. 맨 아래에 판정이 '일치'인 줄이 몇 개인지 한 줄로 적어.
```

끝나면 `team-assets.md`를 팀 저장소 **첫 화면**(이름 폴더들이 보이는 곳)에 올리고, 팀 슬랙에 "team-assets.md 올렸어요"라고 남깁니다.
