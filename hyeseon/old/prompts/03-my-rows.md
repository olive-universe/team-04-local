# 역할 조사: 노트와 내 표 만들기 (공통 실습 · 팀원 모두)

`llm-academy` 폴더에서 Claude Code에 붙여 넣습니다. 노란 칸 두 곳(내가 맡은 분류 `역사·문화`, 내 영어 이름 `seoyun`)만 바꿉니다.
Claude가 자산 2개를 먼저 보여 주면, 괜찮을 때 "좋아"라고 보냅니다.

```text
나는 팀에서 역사·문화 조사를 맡았고, 내 영어 이름은 seoyun이야.
1. keyword-map.md 의 '분류' 칸을 보고, 내 분류에 드는 부산 자산 2개를 골라 목록만 먼저 보여 줘. 내가 "좋아"라고 하면 2번부터 해.
2. 자산마다 웹에서 믿을 만한 출처 3~5개를 고르고(공공기관·공식 발표·언론 기사 우선), 고른 페이지는 직접 열어 읽어.
3. 자산마다 노트를 research/2026-11-13-(자산을 영어로 짧게).md 로 저장해. 구성: ## 요약(문장마다 [1]처럼 출처 번호) · ## 출처 표 | 번호 | 제목 | 발행처 | 발행일 | URL | 원문 문장(그대로) | · ## 확인 못 한 것
4. 페이지에서 직접 확인하지 못한 숫자·날짜는 쓰지 말고 '확인 못 한 것'으로 보내.
5. 끝으로 my-assets.md 를 새로 만들어 자산 하나를 한 줄로 적어: | 자산 | 분류 | 한 줄 설명 | 주 출처 | 독립 출처 URL | 판정 | 담당 |
   독립 출처 = 같은 보도자료를 옮긴 기사가 아닌 두 번째 출처. 판정: 두 출처가 같은 말이면 '일치', 두 번째가 없으면 '독립 출처 없음', 원문을 못 열었으면 '확인 못 함'. 담당 = 내 영어 이름.
```

끝나면 `my-assets.md`와 `research/` 폴더를 팀 저장소의 **내 이름 폴더**에 올립니다(Add file → Upload files → Commit changes).
