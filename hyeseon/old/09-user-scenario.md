# 09 · 대표 사용자 셋의 하루로, 우리 상품을 구체화하기 (5일차 오후)

팀에서 한 사람이 저장소 맨 위 폴더에서 Claude Code를 열고 보냅니다. **Shift + Tab**으로 `⏸ plan mode on`을 켜면 파일을 만들기 전에 계획을 먼저 받습니다. 노란 칸 셋은 팀이 같이 정합니다.

```text
[1. 우리 상품 한 줄] [예) 동래온천 하루 코스: 해운대·서면에 묵는 외국인이 지하철로 온천장에 와서 족욕탕·온천·케이블카·파전을 하루에 즐기는 관광상품. 일행에 유모차·어르신이 있으면 계단이 적은 길로 바꿔 안내한다]
[2. 대표 사용자 셋을 고를 기준] [예) 일행(유모차 · 어르신 · 혼자)과 숙소(해운대 · 서면)가 서로 다른 세 사람]
[3. 빼야 할 것] [예) 팀 자료에 근거가 없는 사람과 장면, 광고 글]

위 세 칸을 기준으로 이 저장소의 우리 팀 자료(.md · .csv)를 읽고 scenario.md를 써 줘.
1. 대표 사용자 3명: 가상 이름, 일행, 숙소, 이동 수단, 오늘 하고 싶은 일(목표), 걱정 한 가지. 칸마다 근거 파일 이름을 적고, 근거가 없으면 [가정]이라고 적어.
2. 사람마다 우리 상품을 쓰는 하루를 5~7단계 표로: | 단계 | 하는 일 | 상품이 해 주는 것 | 막히는 곳 | 근거(파일 · 확인됨/확인 안 됨) |
3. 세 사람을 견주어 상품에 꼭 들어갈 것(셋 모두)과 사람마다 다른 것(선택)을 표로.
4. 팀 자료로 확인되지 않은 것은 지어내지 말고, 맨 끝 '현장에서 확인할 것' 목록에 적어.
```

이렇게 되면 끝: `scenario.md`에 사람 셋, 사람마다 하루 표 하나, 꼭 들어갈 것과 선택 표, 현장에서 확인할 것 목록이 있습니다. 근거 칸이 빈 줄이 없습니다.
