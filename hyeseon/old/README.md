# llm-academy

6주 동안 쓰는 LLM 학습 폴더입니다.

```
llm-academy/
├─ CLAUDE.md          ← ① 나는 누구·목표·선호·규칙
├─ keyword-map.md     ← ② 부산 키워드 12개 이상
├─ SOURCE.md          ← 데이터 출처
├─ README.md
├─ inputs/            ← 부산 공공데이터 CSV
├─ prompts/           ← 세 칸을 채우는 프롬프트
├─ examples/          ← Before / After 예시
└─ research/          ← ③ 리서치 노트 2장 이상
```

## 체크리스트
- [ ] ① CLAUDE.md 채우기
- [ ] ② keyword-map.md에 키워드 12개 이상
- [ ] inputs/에 부산 공공데이터 CSV 넣고 SOURCE.md에 출처 적기
- [ ] ③ research/에 리서치 노트 2장 이상
