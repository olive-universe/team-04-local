# 허심청 리뷰 감정·경험 키워드

- 확인일: 2026-11-16
- 근거: [리뷰 원본](inputs/huhshimchung_reviews_100.csv), [리뷰 코드북](review-codebook.md), [기존 키워드맵](keyword-map.md).
- 원본 파일의 값은 수정하지 않았다. 연번은 CSV의 ‘연번’ 값이며 엑셀 행 번호가 아니다.

## 읽고 센 방법

CSV는 Python의 `csv.DictReader`로 읽었다. 리뷰 안의 줄바꿈을 별도 행으로 세지 않았다. 분석 대상은 100건이다.

코드북의 주제 구분을 유지하고, 감정·경험이 드러나는 문맥을 읽어 키워드를 골랐다. 코드북 자체에 감정 태그를 추가하거나 기준을 고치지 않았다. 대상 없이 전체 칭찬·불만만 있는 글과 내용 없는 마침표는 경험 태그를 붙이지 않았다.

건수는 **문맥을 읽어 분류한 리뷰 연번을 Python으로 중복 제거해 센 리뷰 수**다. 단어 출현 횟수나 자동 감정 분석 결과가 아니다. 한 리뷰에 여러 키워드를 붙일 수 있어 합계는 전체 리뷰 수와 다르다. 아래 표는 선정한 경험 주제 안에서의 빈도이며, 모든 단어의 빈도 상위 목록은 아니다.

긍정·부정·부정문을 함께 확인했다. 예를 들어 ‘휴식·힐링’에는 힐링하지 못했다는 리뷰도 포함한다. 이 수치를 만족한 사람 수로 읽으면 안 된다. 물 자체의 느낌은 수질로, 오염·청소·냄새는 위생으로 읽되 서로 다른 내용이 함께 있으면 중복 분류했다. 피부 변화와 위생 문제는 리뷰 작성자의 경험·주장이며 실제 효능이나 원인을 검증한 사실이 아니다.

## 기존 키워드맵과 비교

현재 `keyword-map.md`에는 이름이 ‘장면’인 열이 없다. 따라서 요청한 칸과의 정확한 대조는 할 수 없다. 대신 실제로 존재하는 **‘바다·밤 장면’ 묶음**과 비교했다.

- **겹치는 말: 온천.** 기존 맵의 ‘바다·밤 장면’ 묶음에 ‘해운대 달맞이온천축제’가 있고, 리뷰에도 “온천은 허심청” (연번 4)이 있다. ‘온천’은 표의 물·피부 느낌과 노천탕 체험을 묶는 상위 경험어다. 겹치는 것은 이 말이며, 두 장소나 체험이 같다는 뜻은 아니다.
- **리뷰에서 새로 나온 구체 경험: 자리 맡기.** 기존 맵에는 이 표현이 없고, 리뷰에는 “그리고 자리맡기 금지라고 안내좀 제대로 해야할듯” (연번 29)이 있다. 표의 혼잡·자리 찾기에 해당한다. ‘리뷰에만’은 이번 비교 대상인 `keyword-map.md`에 없다는 뜻이다.

## 소재 카드

아래는 리뷰를 바탕으로 한 창작 제안이다. 실제 시설 운영을 새로 확인한 사실은 아니다. 캐릭터 이름·성격은 자료에 없어 안내 역할만 제안한다.

### 소재 카드 A — 너무 많아서, 어디부터?

- **쓴 키워드:** 탕의 다양함 26건, 큰 공간·규모감 26건.
- **장면(누가·어디서·무엇을):** 처음 방문한 여행자가 탕 입구에서 넓은 공간을 보고 멈춰 선다. 여러 탕을 둘러보며 자신에게 맞는 첫 체험을 고른다.
- **근거 리뷰 연번:** 1(크기에 압도됨·둘러보는 재미), 14(취향껏 즐기는 다양한 탕), 15(입구의 규모감과 편한 동선), 55(다양한 탕이 재밌음).
- **우리 캐릭터가 설 자리:** 입구의 동선 안내자. 선택지를 짧게 설명하고 ‘먼저 둘러보기’를 돕는다. 정답 코스를 강요하지 않는다. 실제 탕 배치와 온도 정보는 별도 확인 후 사용한다.

### 소재 카드 B — 탕은 많은데, 내 자리는?

- **쓴 키워드:** 탕의 다양함 26건, 혼잡·자리 찾기 12건, 휴식·힐링 8건.
- **장면(누가·어디서·무엇을):** 쉬러 온 방문자가 샤워 공간에서 빈자리를 찾는다. 바구니만 놓인 자리와 붐비는 탕을 보며, 넓은 시설에서도 편히 쉬기 어렵다고 느낀다.
- **근거 리뷰 연번:** 22(자리 맡기 금지 안내와 손님 행동의 충돌), 62(자리 맡기·많은 사람, 이후 한산한 시간의 다른 경험), 65(자리 찾기·혼잡 때문에 힐링 대신 스트레스), 66(샤워 공간 이용의 어려움).
- **우리 캐릭터가 설 자리:** 이용객을 탓하기보다 이용 규칙과 현장을 연결하는 조력자. 비어 있는 공간을 찾는 방법과 자리 맡기 금지 안내를 알려 준다. 확인되지 않은 실시간 혼잡도나 빈자리를 있다고 말하지 않으며 짐으로 자리를 대신 맡아 주지 않는다.

## 집계 근거와 재현용 Python

아래 연번 목록은 문맥을 읽어 분류한 결과이고, 건수는 Python 계산이다. 분류가 적절한지 연번별로 다시 검토할 수 있도록 목록을 공개한다.

```python
import csv
from pathlib import Path

with Path('inputs/huhshimchung_reviews_100.csv').open(
    encoding='utf-8-sig', newline=''
) as f:
    reviews = list(csv.DictReader(f))
by_id = {int(row['연번']): row for row in reviews}
assert len(reviews) == len(by_id) == 100

tags = {
    '탕의 다양함': [1, 3, 9, 11, 14, 15, 16, 17, 19, 25, 27, 29, 30, 32, 33, 34, 40, 52, 55, 62, 65, 67, 74, 78, 86, 97],
    '큰 공간·규모감': [1, 3, 5, 12, 15, 17, 19, 25, 27, 39, 40, 41, 44, 46, 50, 52, 55, 56, 58, 65, 71, 72, 76, 78, 83, 99],
    '물·피부 느낌': [2, 3, 5, 7, 9, 15, 25, 34, 38, 41, 44, 48, 53, 63, 64, 65, 75, 78, 80, 97],
    '가격 부담·돈값': [7, 14, 15, 20, 33, 50, 61, 64, 65, 67, 69, 72, 75, 78, 79, 81, 84, 91, 100],
    '재방문·반복 이용': [1, 9, 11, 15, 18, 19, 24, 28, 29, 32, 37, 38, 65, 67, 69, 78, 81, 86, 89],
    '청결·위생·냄새': [1, 3, 8, 25, 28, 29, 33, 35, 37, 41, 43, 52, 56, 60, 62, 65, 67, 84],
    '음식·간식 경험': [1, 2, 6, 9, 11, 19, 36, 37, 42, 50, 53, 74, 75, 80, 83],
    '혼잡·자리 찾기': [1, 14, 22, 25, 29, 62, 65, 66, 67, 71, 72, 74],
    '노천탕 체험': [1, 11, 33, 35, 42, 48, 65, 67, 72, 86],
    '휴식·힐링': [1, 10, 16, 32, 48, 54, 65, 72],
}
for keyword, ids in tags.items():
    assert len(ids) == len(set(ids))
    assert set(ids) <= set(by_id)
    print(keyword, len(set(ids)))
```
