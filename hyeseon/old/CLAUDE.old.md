# CLAUDE.md — 나에 대한 안내

> Claude가 이 폴더에서 일할 때 가장 먼저 읽는 파일입니다.

## 나는 누구
- 이름/닉네임: (작성 예정)
- 하는 일·배경: (작성 예정)
- LLM 사용 경험: 자주 — 업무나 공부에 매일 쓰다시피 한다. 기초 개념 설명은 생략해도 된다.

## 6주 목표
1. **프롬프트 실력 키우기** — 원하는 결과를 얻는 프롬프트를 스스로 쓸 수 있게 된다. (`prompts/`, `examples/`에 Before / After로 쌓기)
2. **부산 데이터 리서치** — 부산 공공데이터 CSV(`inputs/`)를 근거로 리서치 노트(`research/`)를 쓴다.
3. **Claude Code 익히기** — Claude Code로 파일 정리·데이터 분석 같은 작업을 직접 해 본다.
4. **결과물 하나 완성** — 6주 끝에 보고서나 발표 자료 같은 결과물 하나를 만든다.

## 선호
- 답변 언어: 한국어
- 답변 길이·톤: 자세하고 친절하게. 결론만이 아니라 이유와 예시까지 설명한다.
- 선호 형식: 문단. 자연스러운 문장으로 풀어 쓰고, 목록과 표는 꼭 필요할 때만 쓴다.

## 규칙
- 부산 공공데이터는 `inputs/`의 CSV만 근거로 쓴다. 출처는 `SOURCE.md`에 적는다.
- 숫자·사실을 지어내지 않는다. 모르면 모른다고 말한다.
- 리서치 노트는 `research/YYYY-MM-DD-주제.md` 형식으로 저장한다.
- 프롬프트를 고칠 때는 고치기 전(Before)과 후(After)를 `examples/`에 남긴다.
- 키워드는 `keyword-map.md`를 기준으로 고른다.
