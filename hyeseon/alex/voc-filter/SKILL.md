# 레저보트 구매 VOC 판단 규칙

글마다 아래 순서대로 묻고, **처음 걸리는 곳에서 멈춘다.**

## 1단계 · 뺄 글인가?

| 질문 | 예이면 | 뺀 이유에 적을 말 |
|---|---|---|
| 글 날짜가 2023-01-01 ~ 2026-12-31 밖인가? | 뺌 | 기간 밖 |
| 같은 글(띄어쓰기만 다른 것 포함)이 이미 있나? | 뺌 | 중복 |
| 광고·협찬·업체 홍보인가? (협찬, 광고, 제공받, 원고료, 체험단, 업체가 쓴 판매 글) | 뺌 | 광고 |
| 요트·보트를 **타 본 손님**의 후기인가? (투어, 승선, 체험, 선셋 크루즈, 요트 파티, 예약하고 탔다) | 뺌 | 승선 후기 |
| **어선·영업용 배** 이야기인가? (어선, 어업, 조업, 선장 모집, 낚시어선 영업, 선단, 수협) | 뺌 | 어선 |
| 배와 상관없는 글인가? (가입 인사, 날씨, 잡담) | 뺌 | 관련 없음 |
| 배가 아니라 **부품·장비** 거래 글인가? (어탐기, 선외기 단품, 트레일러, 프로펠러 등) | 뺌 · **따로 보관** | 부품 거래 |

⚠️ 헷갈리기 쉬운 것
- **개인 낚시보트**(내가 사서 낚시하러 나가는 배)는 레저기구라서 **넣는다**. 영업하는 '낚시어선'만 뺀다.
- 투어 손님이라도 "그래서 사려고 알아봤는데…"처럼 **구매 이야기로 넘어가면 넣는다**.

## 2단계 · 넣을 글인가?

아래 둘을 **모두** 만족하면 넣는다.
1. 레저보트(요트, 세일링요트, 모터보트, 고무보트, 수상오토바이, 선외기 달린 보트 등)를 **사려고 알아보거나, 사는 중이거나, 산 뒤 가지고 있는** 사람의 글이다.
2. 불만·불편·걱정·후회가 들어 있다.

둘 중 하나라도 애매하면 → **확인 필요** (사람이 본다).

추가 규칙 (2026-11-26 혜선 결정)
- **파는 사람이 말한 불편도 넣는다.** 예: "고장이 잦아서 판다", "수리하다 지쳤다". 산 뒤 가지고 있던 사람의 경험이므로 주로 7단계.
- **불만이 없는 매물 글**(배 판매·구매 글인데 불만·걱정이 없음) → 뺌, 뺀 이유 '불만 없음 · 매물 예시', **따로 보관**. 나중에 매물 글 예시로 쓴다.
- 글쓴이가 살 사람·가진 사람인지 **모르면 확인 필요**.

## 따로 보관하는 글
- '부품 거래'와 '불만 없음 · 매물 예시'는 빼되 버리지 않는다.
- 판단 표에는 그대로 한 줄씩 적고, 아래 파일에도 따로 모은다 (원문 없이 요약·URL만).
  - `hyeseon/alex/kept-listing-examples.md` (불만 없음 · 매물 예시)
  - `hyeseon/alex/kept-parts.md` (부품 거래)

## 3단계 · 여정 단계 붙이기 (`hyeseon/journey/stages.md`)

| 단계 | 이런 이야기면 |
|---|---|
| 1. 요트를 갖고 싶어져요 | 처음 관심, 면허, 얼마나 드는지 막막함 |
| 2. 중고 매물을 찾아봐요 | 매물 사이트·카페 검색, "가격문의"만 있음, 정보 부족 |
| 3. 매물이 진짜인지 확인해요 | 사기, 허위 매물, 소유자·압류 확인, 판매자 연락 두절 |
| 4. 배를 직접 보러 가요 | 검수, 시운전, 엔진·선체 상태, 숨긴 고장 |
| 5. 값을 정하고 계약해요 | 시세, 흥정, 계약서, 숨은 비용, 계약금 |
| 6. 돈을 보내고 명의를 바꿔요 | 송금, 에스크로, 등록·변경등록, 서류, 구청 |
| 7. 배를 댈 곳을 찾아요 | 계류장, 마리나, 보관, 유지비, 수리 |

한 글이 여러 단계에 걸리면 모두 적는다.

## 4단계 · 불만 유형 붙이기

매물 진위 · 숨은 비용 · 배 상태(엔진·선체) · 서류·명의 · 판매자 응대 · 계류장·보관 · 정보 부족 · 기타

## 적는 모양 (한 글에 한 줄)

| 번호 | 출처 이름 | 글 날짜 | 판단(넣음/뺌/확인 필요) | 뺀 이유 | 단계 | 유형 | 내 말로 줄인 요약 |

- **원문은 이 표에 옮기지 않는다.** 원문은 `raw/` 폴더에만 둔다.
- 작성자 닉네임·연락처는 적지 않는다.
- 요약은 내 말로 한 줄. 글에 없는 감정이나 이유를 지어내지 않는다.
