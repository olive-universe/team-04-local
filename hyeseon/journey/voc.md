# VOC · 리뷰를 고객 여정 단계로 나누기 · 마린딜러

- 작성: 김혜선 · 2026-11-25 (Claude 초안, 혜선 확인 전)
- 기획 목적: 고객의 불편을 고객이 남긴 글로 근거를 세운다
- 리뷰 파일: `yujin/team_reviews.csv` (수영만요트경기장 1~19번 · 광안리해양레포츠센터 20~69번 카카오맵 후기, 칸: 연번·장소·별점·리뷰·등록일·메모)
- 여정 단계: `hyeseon/journey/stages.md`의 1~7단계
- 세는 방법: `hyeseon/journey/count_voc.py` (저장소 맨 위에서 `python hyeseon/journey/count_voc.py`). 눈으로 세지 않았다. 아래 표와 숫자는 이 파일을 돌린 결과를 그대로 붙였다.
- 공개 저장소라 리뷰 원문은 옮기지 않았다. 아래 "불편 요약"은 원문을 내 말로 줄인 것이다. 원문은 연번으로 `yujin/team_reviews.csv`에서 찾는다.
- 건수는 모두 **이 파일 안에서 몇 건**이다. 고객 전체의 비율이 아니다.

## 먼저 알고 볼 것

1. **이 리뷰는 요트 '투어' 손님의 글이다. 요트를 사는 사람(매수인)의 글이 아니다.** 그래서 투어 손님의 상황을 매수인 여정의 비슷한 단계로 바꿔 끼웠다. 예: 업체가 연락에 답하지 않음 → 3단계(판매자에게 연락해 확인), "주차·화장실" → 4단계(배를 보러 현장에 감).
2. 단계는 낱말로만 나눴다. 한 리뷰가 여러 단계에 들어갈 수 있고, 뜻과 다르게 들어간 리뷰가 있을 수 있다. [확인 필요: 사람이 연번별로 다시 보기]
3. 리뷰 중 메모에 "글이 '… 더보기'로 잘림"이 있는 것은 잘린 뒷부분을 세지 못했다.
4. 6단계(돈을 보내고 명의를 바꿔요)는 투어 후기에 나올 수 없는 이야기다. 매수인 인터뷰로만 채울 수 있다.

## 단계를 고르는 규칙 (`count_voc.py`와 같음)

리뷰에 아래 말이 하나라도 있으면 그 단계에 넣는다.

| 여정 단계 | 이런 말이 있으면 | 매수인 여정과 이어지는 까닭 |
|---|---|---|
| 1. 요트를 갖고 싶어져요 | 요트, 노을, 야경, 뷰(단 "리뷰" 안의 "뷰"는 뺌), 낭만, 마천루, 선셋, Yachting | 요트와 바다 풍경을 보고 갖고 싶어지는 순간 |
| 2. 중고 매물을 찾아봐요 | 예약, 인터넷, 패키지, 신청, 몰랐 | 인터넷에서 찾아보고 고르는 순간 |
| 3. 매물이 진짜인지 확인해요 (병목) | 평점, 조작, 공지, 신뢰, 믿, 사기, 전화, 문자 | 믿을 수 있는지 따지고, 상대에게 연락해 확인하는 순간 |
| 4. 배를 직접 보러 가요 | 주차, 화장실, 안내, 어디로, 기다리, 본관, 건물, 시설, 샤워, 탈의, 직원, 강사, 스텝, 친절, 운영, 지하철, 교통, 접근성, 노후, 오래된 | 현장(계류장)에 가서 사람과 시설을 만나는 순간 |
| 5. 값을 정하고 계약해요 | 원에, 원 상당, 000원, 가격, 비용, 요금, price, cost, pay | 값이 얼마인지, 숨은 비용이 있는지 |
| 6. 돈을 보내고 명의를 바꿔요 | 결제, 환불, 송금, 명의, 등록 | 돈과 명의가 넘어가는 순간 |
| 7. 배를 댈 곳을 찾아요 | 정박, 계류, 구청, 임대, 공공 | 배를 둘 자리와 계류장 운영 |

- **불편을 말한 리뷰**: 아래 말이 하나라도 있으면 센다. 최악, 더럽, 악취, 불친절, 극혐, 비추, 아쉬, 부족, 안받, 씹, 못탐, 못봤, 못탔, 무서웠, 노후, 조작, 강제, 공지는 없, 깡패, 반말, 비아냥, poor, 줄어, 제대로 안, 이딴, 타지마, 안좋, 지연
- **뺄 리뷰**: 같은 글(띄어쓰기만 다른 것 포함)이 앞에 이미 있는 리뷰, 광고·협찬이라고 밝힌 리뷰(협찬, 광고, 제공받, 원고료, 체험단)
- **비꼼 후보**: 칭찬 말(좋, 재밌, 재미, 훌륭, 멋, 빼어난, 행복, 최고, 감성)이 있고, 별점이 3점 이하이거나 말끝을 흐리는 표시(.., ?, 하지만, 지만, ㅋㅋ)가 있는 리뷰. 강한 불만 말(최악, 극혐, 더럽, 악취, 불친절, 비추, 깡패)이 있으면 대놓고 불만이라 뺀다. 판단은 사람이 한다.

## 알게 된 것 [내 판단]

- 병목인 3단계에 들어간 리뷰 5건 가운데 3건이 불편을 말했고, 3건 모두 별점 1·2점이다 (이 파일 안에서). 말의 내용은 "연락이 안 됨", "미리 알려 주지 않음", "평점을 못 믿겠음"이다. 가설: 요트를 사는 사람도 "판매자와 연락이 끊김", "미리 알려 주지 않은 조건", "후기·정보를 못 믿겠음"을 겪을 수 있다. [확인 필요: 매수인 인터뷰]
- 불편이 가장 많이 들어간 단계는 4단계(현장)다. 화장실, 주차, 안내, 직원 응대 이야기다.
- 6단계는 0건이다. 매수인의 목소리가 없다는 뜻이지, 불편이 없다는 뜻이 아니다.
