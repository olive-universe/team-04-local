| 태그 | 뜻 | 붙이는 경우 | 안 붙이는 경우 | 예 문장(원문 그대로) |
|---|---|---|---|---|
| 탕·사우나 | 목욕탕 안의 탕과 사우나 구성 | 탕 종류·개수, 물 온도, 이색탕(맥주탕·청자탕 등), 노천탕, 사우나, 목욕탕 크기·넓이를 말할 때 | 물의 느낌·피부 효과 → 수질 / 탕의 냄새·더러움 → 청결·위생 / 찜질방 → 찜질방·식음료 | "탕이 매우 많아서 여기저기 둘러보는 재미가 있음" (1) |
| 수질 | 온천물 자체 | 물의 느낌, 피부가 어떻게 됐는지, 물이 깨끗한지·탁한지, 온천수인지를 말할 때 | 물 온도 → 탕·사우나 / 바닥·거울·화장실 등 물 밖 공간 → 청결·위생 | "물은 나온직후에 피부가 보들보들 해요." (9) |
| 청결·위생 | 공간이 깨끗한지 | 바닥, 탈의실, 거울, 화장실, 냄새, 머리카락, 무좀 등을 말할 때 | 물 자체 → 수질 / 건물이 오래됐다는 말만 있을 때 → 시설·비품 (낡은 것과 더러운 것은 다름) | "남탕 탈의실과 파우더 룸 바닥이 너무 지저분합니다." (60) |
| 시설·비품 | 건물과 갖춰진 물건 | 건물이 오래됐는지, 락카, 바닥재, 수건, 드라이기, 샴푸·면도크림, 썬베드 등을 말할 때 | 목욕탕 크기·탕 구성 → 탕·사우나 / 찜질방 시설 → 찜질방·식음료 / 더러움 → 청결·위생 | "시설 너무 낡았어요 ㅠ" (69) |
| 찜질방·식음료 | 찜질방과 먹고 마시는 것 | 찜질방 크기·구성, 식당·카페·매점, 탕 안 아이스크림·음료, 음식 맛·메뉴·식사 마감 시간을 말할 때 | 찜질 추가요금이나 음식 값만 말할 때 → 가격 / 목욕탕 쪽 사우나 → 탕·사우나 | "찜질방은 동네 찜질방보다 못해요" (40), "돈가스는 어묵맛이 납니다;;" (53) |
| 가격 | 내는 돈 | 입장료, 찜질 추가요금, 세신비, 음식 값, 가성비, 중고 티켓을 말할 때 | 주차 무료 시간 → 직원·운영 / 음식 맛 → 찜질방·식음료 | "이제는 좀 비싸서 부담입니다" (79) |
| 직원·운영 | 직원과 운영 방식 | 직원 태도, 세신, 주차 안내, 주차 무료 시간, 영업시간, 후불 정산, 안내문을 말할 때 | 다른 손님의 행동만 말할 때 → 다른 이용객 (직원이 제지하지 않는다는 말이 있으면 둘 다 붙임) | "주차직원 불친절함" (59) |
| 다른 이용객 | 함께 이용하는 사람들 | 사람이 많은지 적은지, 아이 동반, 자리 맡기, 문신, 다른 손님의 매너를 말할 때 | 직원의 대응 → 직원·운영 | "좋았는데 사람이 너무 많아서 샤워장에서 씻기 힘들었음" (66) |
