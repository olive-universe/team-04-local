# 허심청 리뷰 감정·경험 키워드

- 확인한 날짜: 2026-11-16
- 읽은 파일: inputs/huhshimchung_reviews_100.csv (읽기만 함, 값은 고치지 않음), review-codebook.md, keyword-map.md, keyword-map-부산먹거리.md
- 행 번호 세는 법: 머리줄 = 1행, 그래서 엑셀 행 번호 = 연번 + 1
- 건수 세는 법: 키워드가 **한 번이라도 나온 리뷰의 수**. 한 리뷰에 여러 번 나와도 1건으로 셈. Python 3.12.10으로 셈 (코드는 맨 아래 '셈에 쓴 코드' 섹션)
- 분모: 이 파일의 리뷰 100개 (연번 21, 47은 "." 한 글자뿐). 100개를 고른 기준은 파일에 없어서, 허심청 리뷰 전체의 비율로 말할 수 없음

## 3. 소재 카드

> 장면은 리뷰 말을 재료로 한 **상상**임. '누가'는 리뷰를 쓴 사람이 누군지 파일에 없어서(작성자·국적·방문 목적 칸 없음) 리뷰에 나온 말로만 적음.
> 우리 팀 캐릭터는 폴더 안 어느 파일에도 정해져 있지 않음 [확인 필요: 팀 캐릭터가 아직 정해지지 않음]. 그래서 '설 자리'에는 캐릭터가 설 위치와 할 일만 적음.

| 근거 리뷰 연번 | 65 ("근데 여탕엔 앉을 자리가 하나도 없음."), 66, 71, 72, 74 |
| 우리 캐릭터가 설 자리 | 탕 입구. "평일 오후·아침이 한가해요"를 알려 주는 안내 역할. 근거: "그러나 주말 오후엔 사람이 정말 많으니 아침에 오는 걸 추천한다." (72), "평일 오후에가면 ㄹㅇ개좋음" (48) |

## 셈에 쓴 코드

- 실행: `python count2.py inputs/huhshimchung_reviews_100.csv keyword-map-부산먹거리.md` (코드 파일은 임시 폴더에 두었음. 아래가 전체 코드)

```python
import csv, re, sys
sys.stdout.reconfigure(encoding='utf-8')
rows = list(csv.DictReader(open(sys.argv[1], encoding='utf-8-sig')))
# 키워드: (찾는 말 정규식, 뺄 연번 {연번: 까닭})
K = {
 '낡음·노후': (r'낡|노후|낙후|오래\s?된|오래되|오래\s?됐', {'1': '"노후? 지저분한 느낌 없고" — 낡지 않았다는 뜻'}),
 '아이·애기': (r'애기|애들|아기|어린이|아이(?!스)|유치원|키즈|남아', {'44': '"애기피부" — 아이 이야기가 아님'}),
 '비쌈·부담': (r'비싸|비싼|부담', {}),
 '사람 많음': (r'사람.{0,8}많', {'9': '"사람 너무 많아서" — 허심청이 아니라 센텀 스파랜드 이야기'}),
 '놀람': (r'놀라|놀랬|놀랄|깜짝|충격|식겁|당황', {}),
 '피부': (r'피부', {}),
 '냄새': (r'냄새|남새|찌린내|똥내|구렁내', {}),
 '아이스크림': (r'아이스크림', {}),
 '또 가고 싶다': (r'또\s?(가고|오고|한번 와)', {}),
 '다시 안 간다': (r'다시는 안|안\s?갈|재방문 의사 없|재방문은 절대 안|두번은 안', {}),
 '재미': (r'재미|재밌|잼', {'75': '"노잼" — 재미없다는 뜻'}),
 '압도': (r'압도', {}),
}
# 장면 한 줄 칸 (keyword-map-부산먹거리.md 표의 5번째 칸)
scenes = []
for line in open(sys.argv[2], encoding='utf-8'):
    c = line.split('|')
    if len(c) > 6 and c[3].strip() not in ('키워드', '---'):
        scenes.append((c[3].strip(), c[5].strip()))
for k, (p, ex) in K.items():
    hit = [r for r in rows if re.search(p, r['리뷰'])]
    keep = [r for r in hit if r['연번'] not in ex]
    sc = [n for n, s in scenes if re.search(p, s)]
    print(f'## {k}: 찾음 {len(hit)} / 뺌 {len(hit)-len(keep)} / 건수 {len(keep)} / 장면칸 일치: {sc}')
    for r in keep:
        for ln in r['리뷰'].split('\n'):
            if re.search(p, ln): print(f'  ({r["연번"]}) {ln}')
```
