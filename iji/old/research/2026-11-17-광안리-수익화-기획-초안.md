## 1. 문제: 광안리에서 무엇이 안 풀리고 있나

| 누가 | 무엇이 문제인가 | 근거 |
|---|---|---|
| **손님 (20·30대, 외국인)** | 토요일 밤·축제 날에 **자리 잡기**가 힘들고 **숙박이 비싸다** | 오후 1~3시부터 자리 잡기, 숙박 9만→55만 원, 암표 20만~30만 원 |
| **외국인** | **카드 결제 거부, 다국어 안내 부족, 한국 전화번호 인증** | 부산시 외국인 면접 (카드 12.5%, 다국어 12.5%, 인증 9.4%) |
| **광안리 가게** | 손님은 늘었는데 **가게당 매출은 줄었다** (가게끼리 경쟁) | 광안2동 구역당 점포 +29.6%, 구역당 매출 -7.3% |

**한 문장 (가설):** 손님은 몰리는데, 손님은 불편하고 가게는 경쟁에 지친다. **둘을 이어 주는 쪽에 돈이 있다.**

## 2. 수익 모델 비교

| 기준 | A. 밤 미식 코스 | B. 관람 패키지 | C. 가게 홍보·쿠폰 |
|---|---|---|---|
| 무엇 | 토요일 밤 오션뷰 카페·디저트·맛집 코스 | 불꽃축제·드론쇼 관람석 + 식사 + 공정가격 숙소 | 해외카드·다국어 되는 가게 목록 + 쿠폰 |
| 타깃 | 20대 여성 + 외국인 | 30대 + 외국인 | 외국인 (+ 20대) |
| 돈은 누가 내나 | 손님 (코스 이용료) 또는 가게 (제휴 수수료) | 손님 (패키지 가격) | **가게** (광고비·쿠폰 수수료) |
| 자료 근거 | ★★★ 20대 여성 1위, 밤 매출 44.8%, 외국인 식도락 만족 19.2% | ★★★ 불꽃축제 날 지출 1위, 숙박·자리 불만, 서울 카페 관람석 1시간 매진 | ★★ 가게당 매출 감소, 외국인 불편 |
| 언제 돈이 되나 | 매주 토요일 (1년 내내) | **1년에 며칠** (불꽃축제·10월) | 1년 내내 |
| 학생 팀이 6주 안에 만들 수 있나 | ○ 웹페이지 + 코스 지도 | △ 좌석·숙소 계약이 필요 | ○ 웹페이지 + 가게 목록 |
| 로블록스·웹과 잘 맞나 | ○ 맵에서 코스 미리 걷기 | ○ 맵에서 불꽃·드론쇼 미리 보기 | ○ 맵 속 가게 간판 = 광고 자리 |
| 위험 | 비슷한 맛집 지도 많음 | 바가지 이미지, 날씨, 안전 | 가게가 돈을 낼지 모름 |

### 추천 (가설): **A + C를 기본으로, B는 시즌 이벤트로**

- **평소 (매주 토요일):** A 코스와 C 가게 쿠폰을 하나의 웹페이지로 합친다 → "광안리 토요일 밤 가이드"
- **시즌 (10월, 불꽃축제):** B를 한정 이벤트로 연다 → 같은 웹페이지에 '관람 패키지' 탭을 추가
- 이유
  - A만 하면 돈을 받을 곳이 약하다.
  - C만 하면 손님이 올 이유가 약하다.
  - B는 1년에 며칠뿐이다. 합치면 서로의 약점을 메운다.

## 3. 서비스 그림

```
① 관심 끌기                    ② 정보·예약                    ③ 실제 방문 = 매출
[로블록스 '광안리 토요일 밤']  →  [웹페이지 '광안리 나이트']  →  [광안리 제휴 가게]
 - 드론쇼 시간에 맞춰 열림         - 한국어·영어·중국어·일본어      - 쿠폰 사용
 - 가게 간판 = 제휴 가게           - 해외카드 되는 가게 표시          - 사용 수 = 가게에 보여 줄 성과
 - 맵에서 쿠폰 코드 획득           - 전화번호 없이 예약
                                   - 20대 여성용 포토스팟 코스
[인스타그램·숏폼]  ───────────→   - (시즌) 관람 패키지 탭
 외국인·20대 여성
```

- 태환 님 로블록스 맵에 이미 가게(`ShopInteractions`, `ShopUI`)와 드론쇼 시간(`ShowClock`) 파일이 있다. → 가게 간판을 실제 제휴 가게로 바꾸면 된다.

## 10. 방향 수정: '토요일 밤 전용'이 아니라 '상시 + 피크 강화' (2026-11-17, 김이지 의견 반영)

**김이지 의견:** 전반적인 수익 창출 기획을 먼저 세우고, 유입이 더 많은 토요일 밤은 **거기에 더 특화**하는 것은 좋다. 하지만 **그날에만 파는 상품**은 별로다.

**자료도 같은 방향이다.**

| 근거 | 내용 | 출처 |
|---|---|---|
| 밤 매출은 매일 있다 | 민락동 매출의 44.8%가 18~23시 (부산시 시간대 자료에는 요일 칸이 없다. 그래서 토요일만의 숫자가 아니다) | 전체 정리 2절 |
| 평일에도 사람이 온다 | 광안리 유동인구 2026년 9월에 가장 적은 날도 102844 (9/8 화). 토요일 1위는 180060 (9/12) | 전체 정리 3-4 |
| 성수기가 여러 번 있다 | 내국인 8월, 외국인 10월, 불꽃축제 날, 매주 토요일 | 전체 정리 4절 |
| 외국인은 1년 내내 늘었다 | 수영구 외국인 관광지출 해마다 증가 | 전체 정리 5절 |

### 고친 구조 (가설)

```
[기본: 매일 · 1년 내내]  광안리 다국어 가이드 웹 + 제휴 가게 쿠폰 (C + A의 상시 코스)
        │
        ├─ 매주 토요일: 드론쇼 시간 맞춤 코스 · 쿠폰 혜택 강화
        ├─ 8월: 내국인 여름 (해수욕) 코스
        ├─ 10월: 외국인 (국경절 · 페스티벌 시월) 다국어 홍보 강화
        └─ 불꽃축제 날: 관람 패키지 (B, 한정)
```

| 층 | 언제 | 무엇 | 돈 |
|---|---|---|---|
| **기본** | 매일 | 해외카드·다국어 가게 목록, 밤 코스, 상시 쿠폰 | 가게 월 광고비, 쿠폰 수수료 |
| **강화 1** | 매주 토요일 | 드론쇼 전후 코스, 토요일 한정 쿠폰 혜택 | 쿠폰 수수료 증가분 |
| **강화 2** | 8월 · 10월 | 계절 코스, 대상 언어 홍보 | 광고비 시즌 요금 (가설) |
| **이벤트** | 불꽃축제 날 | 관람석 + 식사 + 공정가격 숙소 | 패키지 판매 |

- **한 줄 차별점 (고친 것):** "광안리를 **언제 와도** 쓸 수 있는 설치 없는 다국어 가이드. **사람이 몰리는 날(토요일 밤·8월·10월·불꽃축제)**에는 혜택을 더 키운다."

### 광안리엔 확인 결과

- 김이지 휴대폰 앱스토어 검색 결과 **"광안리엔" 앱 없음** (2026-11-17).
- 수영구가 2021년에 '가게 정보 + 할인쿠폰' 앱을 만들었지만 지금은 찾을 수 없다. 가설: 앱 설치 부담, 정보 갱신 중단. → 우리는 **설치 없는 웹 + 상시 갱신(제휴 가게가 직접 수정)**으로 간다.
