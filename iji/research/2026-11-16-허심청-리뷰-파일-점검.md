# 허심청 리뷰 파일 점검

- 확인한 날짜: 2026-11-16
- 점검한 파일: inputs/huhshimchung_reviews_100.csv
- 한 일: 파일을 읽기만 함 (값은 고치지 않음)
- 행 번호 세는 법: 머리줄 = 1행, 그래서 엑셀 행 번호 = 연번 + 1

## 1. 행 수와 칸 이름

- 데이터 100행 (2행~101행). 출처: huhshimchung_reviews_100.csv 2~101행
- 칸 4개: 연번, 별점, 리뷰, 등록일. 출처: huhshimchung_reviews_100.csv 1행
- 연번은 1~100이고 겹치는 번호가 없음
- 별점별 행 수: 5점 52, 4점 19, 3점 7, 2점 7, 1점 15. 출처: huhshimchung_reviews_100.csv 2~101행 '별점' 칸
  - 분모가 무엇인지는 파일에 없음 (전체 리뷰 중 이 100개를 고른 기준이 없음)

## 2. 빈 리뷰와 중복 리뷰

- 완전히 비어 있는 리뷰: 0행
- 같은 글이 두 번 나온 경우: 1쌍
  - 연번 21 (22행): 리뷰 "." / 별점 5 / 등록일 2026-04-08
  - 연번 47 (48행): 리뷰 "." / 별점 5 / 등록일 2025-09-10
- 메모: 두 행 모두 마침표 하나뿐이라 내용이 없음. 분석할 때 어떻게 처리할지는 아직 정하지 않음

## 3. 한국어가 아닌 리뷰

- 0개. 리뷰마다 영어·일본어(가나)·한자가 섞였는지 세어 봤고, 다른 언어로 쓰인 리뷰는 없었음
- 연번 21, 47 (22행, 48행)은 글자가 없어서 어느 언어인지 판단할 수 없음

## 4. 날짜 범위

- 가장 오래된 날짜: 2024-03-22. 출처: huhshimchung_reviews_100.csv 101행 (연번 100)
- 가장 최근 날짜: 2026-11-14. 출처: huhshimchung_reviews_100.csv 2행 (연번 1)
- 모든 날짜가 YYYY-MM-DD 형식이고, 연번이 커질수록 날짜가 오래됨

## 5. 이 파일만으로 말할 수 없는 것

1. 리뷰가 어디서 왔는지, 무엇을 골랐는지: 플랫폼 이름, 수집 날짜, 100개를 고른 기준 칸이 없음 → 허심청 리뷰 전체를 대표하는 비율로 말할 수 없음
2. 누가, 언제 방문했는지: 작성자, 방문 날짜, 국적, 방문 목적 칸이 없음. '등록일'은 글을 올린 날이지 방문한 날이 아님 → 외국인 반응이나 축제 기간 반응으로 말할 수 없음
3. 리뷰 내용이 사실인지: 시설·가격 같은 내용은 한 사람의 후기일 뿐임
   - 예: 연번 1 (2행) "샤워공간에 면도크림까지 비치되어있음" [확인 필요: 허심청 공식 안내에 나와 있는지]
