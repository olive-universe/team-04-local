# CLAUDE.md · 김이지의 학습 폴더

> `CLAUDE.template.md` 양식을 따라 채웠습니다. 비밀번호·전화번호·접속 코드는 적지 않습니다. 200줄을 넘기지 않습니다.

## 1. 나는 누구

- 트랙: AX 데이터 서비스 트랙
- 분야: 푸드
- 팀: 올리브 유니버스, 팀원 전태환, 김이지, 김혜선
- 전공·경력: 행정학과 졸업
- 잘하는 것: 자료 조사 및 정리
- 아직 낯선 것: 모든 것 (아직 다 어려워요)

## 2. 6주 목표

- 내 학습목표: [직접 채우기: 어제 쓴 학습목표 문장을 그대로 붙여 넣기]
- 6주 뒤 내가 손에 쥘 결과물: 우리 팀이 6주 동안 부산 먹거리 축제 8개를 한 장으로 정리한 결과물 (키워드 맵 `keyword-map-부산먹거리.md`에서 시작)
- 그걸 위해 이번 주에 할 것: 키워드 맵의 '노트' 칸을 채우고, 아직 노트가 없는 먹거리 축제 5개(미역다시마·밀·커피·건맥·한우)의 리서치 노트를 `research/`에 쓰기

## 3. 선호 작업 방식

- 설명은 쉬운 말과 단계별 번호로 해 주세요. 경로가 나오면 "어느 폴더 안의 어느 파일"인지 풀어 주세요.
- 한 번에 3단계 이상 시키지 말고, 끝날 때마다 확인을 받아 주세요.
- 파일을 만들거나 고치기 전에 파일 이름과 바꿀 내용을 먼저 말해 주세요.
- 원본은 덮어쓰지 않습니다. 고칠 때는 문서 끝에 '정정 기록'(고치기 전 · 고친 뒤 · 까닭)을 남깁니다.
- 하루가 끝나면 `데일리노트/YYYY-MM-DD(요일) 제목.md`에 '오늘 배운 것', '포트폴리오용 문장', '다음에 할 일'로 정리합니다.

## 4. 할루시네이션 방지 규칙 (지우지 마세요)

- 숫자·날짜·인명·인용에는 반드시 출처 URL을 붙입니다. URL이 없으면 쓰지 않습니다.
- 직접 열어 확인하지 못한 내용은 `[확인 필요: 무엇]`으로 표시합니다.
- 한 출처에만 있는 주장은 "○○ 보도에 따르면"이라고 출처를 밝혀 씁니다.
- 회사가 밝히지 않은 이유는 사실처럼 쓰지 않고 "가설:"로 씁니다.
- 리서치 결과는 채팅 답으로 끝내지 말고 `research/` 폴더에 노트 파일로 저장합니다.
- 노트에는 확인한 날짜(YYYY-MM-DD)를 적습니다.

### 내가 더한 규칙 (지금까지 실제로 지켜 온 것)

- `inputs/` 파일은 읽기만 하고 고치거나 새로 만들지 않습니다.
- `inputs/` 숫자는 파일 값 그대로 씁니다. 반올림하거나 새 숫자를 만들지 않습니다. 출처는 URL 대신 "파일 이름 + 엑셀 행 번호(머리줄 = 1행)"로 붙입니다.
- 두 파일의 숫자가 서로 다르면 하나를 고르지 않고 둘 다 적습니다. (예: 방문자 증감률 0.8 / 0.9)
- 비율의 분모가 파일에 없으면 "분모가 무엇인지는 파일에 없음"이라고 적습니다.
- 웹 출처는 페이지를 직접 열어 읽은 것만 씁니다. 검색 결과 요약(스니펫)에서만 본 숫자·날짜는 '## 확인 못 한 것' 섹션으로 보냅니다.
- 원문 문장은 한 글자도 바꾸지 않고 옮깁니다(따옴표 모양까지).
- 행사 전에 나온 기사의 "~한다", "~할 예정이다"를 "~했다"로 바꿔 쓰지 않습니다. 실제로 열렸는지 확인하지 못했으면 "예고됐다"로 씁니다.
- 리서치 노트 파일 이름은 `research/YYYY-MM-DD-주제.md`이고, 단어 사이는 하이픈(`-`)으로 잇습니다.
